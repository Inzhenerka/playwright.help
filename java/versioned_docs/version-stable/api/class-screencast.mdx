### showActions {/* #screencast-show-actions */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showActions</x-search>

Включает визуальные аннотации для элементов, с которыми выполняется взаимодействие. Возвращает объект Disposable, при освобождении которого отображение действий прекращается.

**Использование**

```java
Screencast.showActions();
Screencast.showActions(options);
```

**Аргументы**
- `options` `Screencast.ShowActionsOptions` *(необязательно)*
  - `setCursor` `enum ScreencastCursor { NONE, POINTER }` *(необязательно)* <font size="2">Добавлено в: v1.61</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-cursor"/><a href="#screencast-show-actions-option-cursor" class="list-anchor">#</a>
    
    Визуальное обозначение курсора, отображаемое при действиях с указателем. Значение `"pointer"` (по умолчанию) отображает указатель мыши, который анимированно перемещается от точки предыдущего действия к точке следующего. Значение `"none"` отключает отображение курсора.
  - `setDuration` [double] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-duration"/><a href="#screencast-show-actions-option-duration" class="list-anchor">#</a>
    
    Продолжительность отображения каждой аннотации в миллисекундах. По умолчанию — `500`.
  - `setFontSize` [int] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-font-size"/><a href="#screencast-show-actions-option-font-size" class="list-anchor">#</a>
    
    :::warning[Устарело]
    Вместо этого используйте `title` в [setStyle](/api/class-screencast.mdx#screencast-show-actions-option-style), например `style: { title: 'font-size: 32px' }`.
    :::
    
    
    Размер шрифта заголовка действия в пикселях. По умолчанию — `24`.
  - `setPosition` `enum AnnotatePosition { TOP_LEFT, TOP, TOP_RIGHT, BOTTOM_LEFT, BOTTOM, BOTTOM_RIGHT }` *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-position"/><a href="#screencast-show-actions-option-position" class="list-anchor">#</a>
    
    Положение наложения с заголовком действия. По умолчанию — `"top-right"`.
  - `setStyle` Style *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-style"/><a href="#screencast-show-actions-option-style" class="list-anchor">#</a>
    - `setPoint` [String] *(необязательно)*
      
      CSS-объявления для маркера в точке действия. Маркер располагается в точке действия, имеет нулевой размер и центрируется относительно этой точки, поэтому его размер и внешний вид определяются этим стилем. Если параметр не указан, маркер не отображается.
    - `setHighlight` [String] *(необязательно)*
      
      CSS-объявления для прямоугольника, покрывающего целевой элемент. Положение и размеры прямоугольника соответствуют границам элемента. Если параметр не указан, прямоугольник не отображается.
    - `setTitle` [String] *(необязательно)*
      
      CSS-объявления для заголовка действия, например `'font-size: 32px; background: #333'`. Заголовок располагается в соответствии с [setPosition](/api/class-screencast.mdx#screencast-show-actions-option-position).
    
    Стили визуальных обозначений действий. Все обозначения плавно исчезают в течение времени, заданного в [setDuration](/api/class-screencast.mdx#screencast-show-actions-option-duration).
    
    **Использование**
    
    ```js
    await page.screencast.showActions({
      style: {
        point: 'width: 20px; height: 20px; border-radius: 50%; background: red',
        highlight: 'outline: 2px solid #333; background: rgba(0, 128, 255, .15)',
        title: 'font-size: 16px',
      },
    });
    ```
    
**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-return"/><a href="#screencast-show-actions-return" class="list-anchor">#</a>

### showChapter {/* #screencast-show-chapter */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showChapter</x-search>

Показывает наложение для главы с заголовком и необязательным описанием, расположенное по центру страницы на размытом фоне. Полезно для пояснения происходящего в видеозаписях. Наложение удаляется через указанное время или через 2000 мс.

**Использование**

```java
Screencast.showChapter(title);
Screencast.showChapter(title, options);
```

**Аргументы**
- `title` [String]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-title"/><a href="#screencast-show-chapter-option-title" class="list-anchor">#</a>
  
  Текст заголовка, заметно выделенный в наложении.
- `options` `Screencast.ShowChapterOptions` *(необязательно)*
  - `setDescription` [String] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-description"/><a href="#screencast-show-chapter-option-description" class="list-anchor">#</a>
    
    Необязательный текст описания, отображаемый под заголовком.
  - `setDuration` [double] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-duration"/><a href="#screencast-show-chapter-option-duration" class="list-anchor">#</a>
    
    Продолжительность в миллисекундах, по истечении которой наложение автоматически удаляется. По умолчанию — `2000`.

**Возвращает**
- [void]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-return"/><a href="#screencast-show-chapter-return" class="list-anchor">#</a>

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showOverlay</x-search>

Добавляет наложение с заданным HTML-содержимым. Наложение отображается поверх страницы до его удаления. Возвращает объект Disposable, при освобождении которого наложение удаляется.

**Аргументы**

  HTML-содержимое наложения.
- `options` `Screencast.ShowOverlayOptions` *(необязательно)*
  - `setDuration` [double] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-option-duration"/><a href="#screencast-show-overlay-option-duration" class="list-anchor">#</a>
    
    Продолжительность в миллисекундах, по истечении которой наложение автоматически удаляется. Если параметр не указан, наложение остаётся до явного удаления.

**Возвращает**

### start {/* #screencast-start */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.start</x-search>

Запускает скринкаст. Если указан [setPath](/api/class-screencast.mdx#screencast-start-option-path), сохраняет видеозапись в указанный файл. Если указан [setOnFrame](/api/class-screencast.mdx#screencast-start-option-on-frame), передаёт кадры, закодированные в формате JPEG, в функцию обратного вызова. Оба параметра можно использовать одновременно.

**Использование**

**Аргументы**
- `options` `Screencast.StartOptions` *(необязательно)*
  - `setFps` [int] *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-fps"/><a href="#screencast-start-option-fps" class="list-anchor">#</a>
    
    Частота кадров видеозаписи в кадрах в секунду. Используется только вместе с [setPath](/api/class-screencast.mdx#screencast-start-option-path). По умолчанию — `25`.
    
    Более высокая частота кадров делает анимацию и прокрутку более плавными, но увеличивает нагрузку на процессор при кодировании. Используйте вместе с [setSize](/api/class-screencast.mdx#screencast-start-option-size) для записи видео высокого разрешения. Видео может содержать не больше уникальных кадров, чем создаёт браузер; Firefox и WebKit в настоящее время захватывают до 25 кадров в секунду.
  - `setOnFrame` [Consumer]&lt;ScreencastFrame&gt; *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-on-frame"/><a href="#screencast-start-option-on-frame" class="list-anchor">#</a>
    - `setData` [byte&#91;&#93;]
      
      Данные кадра, закодированные в формате JPEG.
    - `setTimestamp` [double]
      
      Временная метка момента отображения кадра браузером, в миллисекундах с начала эпохи Unix.
    - `setViewportWidth` [int]
      
      Ширина области просмотра страницы в момент захвата кадра.
    - `setViewportHeight` [int]
      
      Высота области просмотра страницы в момент захвата кадра.
    
    Функция обратного вызова, получающая данные кадра, закодированные в формате JPEG, вместе с размером области просмотра страницы в момент захвата.
  - `setPath` [Path] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-path"/><a href="#screencast-start-option-path" class="list-anchor">#</a>
    
    Путь, по которому следует сохранить видео при остановке скринкаста. Если указан, запускается запись видео.
  - `setQuality` [int] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-quality"/><a href="#screencast-start-option-quality" class="list-anchor">#</a>
    
    Качество изображения в диапазоне от 0 до 100.
  - `setSize` Size *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-size"/><a href="#screencast-start-option-size" class="list-anchor">#</a>
    - `setWidth` [int]
      
      Максимальная ширина кадра в пикселях.
    - `setHeight` [int]
      
      Максимальная высота кадра в пикселях.
    
    Задаёт размеры кадров скринкаста. Фактический кадр масштабируется с сохранением соотношения сторон страницы и может быть меньше указанных границ. Если скринкаст уже активен (например, запущен при трассировке или записи видео), существующая конфигурация имеет приоритет, и размер кадра может превышать эти границы либо этот параметр может быть проигнорирован. Если параметр не указан, размер будет равен размеру области просмотра страницы, уменьшенному так, чтобы вписаться в 800×800.

**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-return"/><a href="#screencast-start-return" class="list-anchor">#</a>
