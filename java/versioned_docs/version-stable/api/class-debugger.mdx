API для управления отладчиком Playwright. Отладчик позволяет приостанавливать выполнение скрипта и исследовать страницу. Получить экземпляр отладчика можно с помощью [BrowserContext.debugger()](/api/class-browsercontext.mdx#browser-context-debugger).


---

## Методы

### next {/* #debugger-next */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>debugger.next</x-search>

Возобновляет выполнение скрипта и снова приостанавливает его перед следующим действием. Выбрасывает исключение, если отладчик не находится в состоянии паузы.

**Использование**

```java
Debugger.next();
```

**Возвращает**
- [void]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="debugger-next-return"/><a href="#debugger-next-return" class="list-anchor">#</a>

### pausedDetails {/* #debugger-paused-details */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>debugger.pausedDetails</x-search>

Возвращает сведения о вызове, выполнение которого в данный момент приостановлено. Возвращает `null`, если отладчик не находится в состоянии паузы.

**Использование**

```java
Debugger.pausedDetails();
```

**Возвращает**
- [null] | PausedDetails<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="debugger-paused-details-return"/><a href="#debugger-paused-details-return" class="list-anchor">#</a>
  - `location` Location
    - `file` [String]
      
      
    - `line` [int] *(необязательно)*
      
      
    - `column` [int] *(необязательно)*
      
      
    
  - `title` [String]
    
    
---

### requestPause {/* #debugger-request-pause */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>debugger.requestPause</x-search>

Настраивает отладчик на приостановку выполнения перед следующим действием.

Выбрасывает исключение, если отладчик уже находится в состоянии паузы. Используйте [Debugger.next()](/api/class-debugger.mdx#debugger-next) или [Debugger.runTo()](/api/class-debugger.mdx#debugger-run-to) для пошагового выполнения в состоянии паузы.

Обратите внимание, что [Page.pause()](/api/class-page.mdx#page-pause) эквивалентен инструкции "debugger" — он немедленно приостанавливает выполнение в месте вызова. Напротив, [Debugger.requestPause()](/api/class-debugger.mdx#debugger-request-pause) эквивалентен команде «приостановить на следующей инструкции» — он настраивает отладчик на приостановку выполнения перед следующим действием.

**Использование**

```java
Debugger.requestPause();
```

**Возвращает**
- [void]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="debugger-request-pause-return"/><a href="#debugger-request-pause-return" class="list-anchor">#</a>

### runTo {/* #debugger-run-to */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>debugger.runTo</x-search>

Возобновляет выполнение скрипта и приостанавливает его, когда действие вызывается из указанного места в исходном коде. Выбрасывает исключение, если отладчик не находится в состоянии паузы.

**Использование**

```java
Debugger.runTo(location);
```

**Аргументы**
- `location` Location<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="debugger-run-to-option-location"/><a href="#debugger-run-to-option-location" class="list-anchor">#</a>
  - `setFile` [String]
    
    
  - `setLine` [int] *(необязательно)*
    
    
  - `setColumn` [int] *(необязательно)*
    
    
  Место в исходном коде, в котором следует приостановить выполнение.

**Возвращает**
- [void]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="debugger-run-to-return"/><a href="#debugger-run-to-return" class="list-anchor">#</a>
