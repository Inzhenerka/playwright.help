## Введение

Playwright поставляется с `playwright-cli` — интерфейсом командной строки для автоматизации браузера, разработанным для агентов программирования. Он обеспечивает экономное по расходу токенов управление браузером с помощью кратких CLI-команд и устанавливаемых навыков (skills). Это делает его идеальным инструментом для агентов, которым необходимо совмещать автоматизацию браузера с работой над большими кодовыми базами и рассуждениями в пределах ограниченного контекстного окна.

### `playwright-cli` и Playwright MCP
- **`playwright-cli`** лучше всего подходит для **агентов программирования** (Claude Code, GitHub Copilot и т. д.), ориентированных на экономные по расходу токенов рабочие процессы на основе навыков. CLI-команды позволяют не загружать в контекст модели большие схемы инструментов и подробные деревья доступности.
- **MCP** лучше всего подходит для специализированных циклов работы агентов, которым полезны сохранение состояния и итеративные рассуждения о структуре страницы, например для исследовательской автоматизации или длительных автономных рабочих процессов. См. [руководство по началу работы с MCP](./getting-started-mcp.mdx).

## Предварительные требования

Прежде чем начать, убедитесь, что у вас установлены:
- [Node.js](https://nodejs.org/) версии 20 или новее
- Агент программирования: Claude Code, GitHub Copilot или аналогичный

## Установка

Установите `playwright-cli` глобально:

```bash
npm install -g @playwright/cli@latest
playwright-cli --help
```

Либо установите `@playwright/cli` как локальную зависимость и используйте `npx`:

```bash
npm install -D @playwright/cli@latest
npx playwright cli --help
```

### Установка навыков

Агенты программирования, такие как Claude Code и GitHub Copilot, могут использовать локально установленные навыки для получения более подробного контекста о доступных командах:

```bash
playwright-cli install --skills
```

Чтобы использовать навыки во всех своих проектах, добавьте флаг `-g` для их установки в домашний каталог (`~/.claude/skills` или, при использовании `--skills=agents`, `~/.agents/skills`):

```bash
playwright-cli install --skills -g
```

### Работа без навыков

Вы также можете напрямую указать агенту на CLI и позволить ему самостоятельно изучить команды:

```txt
Протестируй сценарий «добавление задачи» на https://demo.playwright.dev/todomvc с помощью playwright-cli.
Посмотри доступные команды в playwright-cli --help.
```

## Первые шаги

### Интерактивная демонстрация

Попробуйте попросить своего агента программирования:

```txt
Используй навыки playwright для тестирования https://demo.playwright.dev/todomvc/.
Сделай скриншоты для всех успешных и неуспешных сценариев.
```

### Пошаговое выполнение вручную

Вы также можете выполнять команды вручную, чтобы понять, как работает CLI:

```bash
playwright-cli open https://demo.playwright.dev/todomvc/ --headed
playwright-cli type "Buy groceries"
playwright-cli press Enter
playwright-cli type "Water flowers"
playwright-cli press Enter
playwright-cli check e21
playwright-cli screenshot
```

После каждой команды CLI выводит снимок текущего состояния страницы:

```txt
### Page
- Page URL: https://demo.playwright.dev/todomvc/#/
- Page Title: React • TodoMVC
### Snapshot
[Snapshot](.playwright-cli/page-2026-02-14T19-22-42-679Z.yml)
```

## Основные команды

### Взаимодействие со страницами

```bash
playwright-cli open [url]               # открыть браузер, при необходимости перейти по указанному URL
playwright-cli goto <url>               # перейти по указанному URL
playwright-cli click <ref> [button]     # нажать на элемент
playwright-cli type <text>              # ввести текст в редактируемый элемент
playwright-cli fill <ref> <text>        # заполнить редактируемый элемент текстом
playwright-cli select <ref> <value>     # выбрать пункт в раскрывающемся списке
playwright-cli check <ref>              # установить флажок или выбрать радиокнопку
playwright-cli uncheck <ref>            # снять флажок
playwright-cli hover <ref>              # навести указатель на элемент
playwright-cli drag <startRef> <endRef> # выполнить перетаскивание между элементами
playwright-cli upload <files...>        # загрузить один или несколько файлов
playwright-cli close                    # закрыть страницу
```

### Выбор целевых элементов

Используйте ссылки на элементы из снимков, чтобы указать целевые элементы:

```bash
playwright-cli snapshot                 # получить снимок со ссылками на элементы
playwright-cli click e15                # нажать на элемент по ссылке
```

Вы также можете использовать CSS-селекторы или селекторы по роли:

```bash
playwright-cli click "#main > button.submit"
playwright-cli click "role=button[name=Submit]"
playwright-cli click "#footer >> role=button[name=Submit]"
```

### Скриншоты и снимки состояния

```bash
playwright-cli snapshot                 # сделать снимок состояния страницы
playwright-cli snapshot --filename=f    # сохранить снимок в указанный файл
playwright-cli screenshot               # сделать скриншот текущей страницы
playwright-cli screenshot [ref]         # сделать скриншот указанного элемента
playwright-cli screenshot --filename=f  # сохранить с указанным именем файла
playwright-cli screenshot --hires       # сделать скриншот в пикселях устройства
playwright-cli pdf                      # сохранить страницу в формате PDF
```

### Навигация

```bash
playwright-cli go-back                  # перейти назад
playwright-cli go-forward               # перейти вперёд
playwright-cli reload                   # перезагрузить страницу
```

### Клавиатура и мышь

```bash
playwright-cli press <key>              # нажать клавишу (например, Enter, ArrowLeft)
playwright-cli keydown <key>            # зажать клавишу
playwright-cli keyup <key>              # отпустить клавишу
playwright-cli mousemove <x> <y>        # переместить указатель мыши
playwright-cli mousedown [button]       # зажать кнопку мыши
playwright-cli mouseup [button]         # отпустить кнопку мыши
playwright-cli mousewheel <dx> <dy>     # выполнить прокрутку
```

### Вкладки

```bash
playwright-cli tab-list                 # вывести список всех вкладок
playwright-cli tab-new [url]            # создать новую вкладку
playwright-cli tab-select <index>       # выбрать вкладку
playwright-cli tab-close [index]        # закрыть вкладку
```

### Сеть

```bash
playwright-cli requests                 # вывести список сетевых запросов с момента загрузки страницы
playwright-cli request <num>            # показать полную информацию об отдельном запросе
playwright-cli route <pattern> [opts]   # имитировать сетевые запросы
playwright-cli route-list               # вывести список активных маршрутов
playwright-cli unroute [pattern]        # удалить маршруты
```

### Хранилище

```bash
playwright-cli state-save [filename]    # сохранить состояние хранилища (cookies, localStorage)
playwright-cli state-load <filename>    # загрузить состояние хранилища

# Файлы cookie
playwright-cli cookie-list [--domain]   # вывести список файлов cookie
playwright-cli cookie-get <name>        # получить файл cookie
playwright-cli cookie-set <name> <val>  # установить файл cookie
playwright-cli cookie-delete <name>     # удалить файл cookie
playwright-cli cookie-clear             # удалить все файлы cookie

# localStorage
playwright-cli localstorage-list        # вывести список записей
playwright-cli localstorage-get <key>   # получить значение
playwright-cli localstorage-set <k> <v> # установить значение
playwright-cli localstorage-delete <k>  # удалить запись
playwright-cli localstorage-clear       # удалить все записи
```

### Инструменты разработчика

```bash
playwright-cli console [min-level]      # вывести список сообщений консоли
playwright-cli eval <func> [ref]        # выполнить JavaScript на странице
playwright-cli run-code <code>          # выполнить фрагмент кода Playwright
playwright-cli tracing-start            # начать запись трассировки
playwright-cli tracing-stop             # остановить запись трассировки
playwright-cli video-start              # начать запись видео
playwright-cli video-chapter <title>    # добавить маркер главы в видео
playwright-cli video-stop --filename=f  # остановить запись видео
```

### WebMCP

Страницы могут регистрировать собственные инструменты для агентов через экспериментальный API [WebMCP](https://webmachinelearning.github.io/webmcp/). Инструменты, зарегистрированные страницей, перечислены в начале снимка состояния страницы, и их можно вызывать напрямую:

```bash
playwright-cli webmcp-list                       # вывести список инструментов, зарегистрированных страницей
playwright-cli webmcp-call <name> [--params]     # вызвать инструмент, передав объект JSON
```

Имена, описания, схемы и результаты инструментов предоставляются страницей, поэтому рассматривайте их как недоверенные входные данные.

## Сессии

По умолчанию CLI хранит профиль браузера в памяти: файлы cookie и состояние хранилища сохраняются между вызовами в рамках сессии, но теряются при закрытии браузера. Используйте `--persistent`, чтобы сохранять профиль на диск.

### Именованные сессии

Запускайте несколько экземпляров браузера для разных проектов:

```bash
playwright-cli open https://playwright.dev
playwright-cli -s=example open https://example.com --persistent
playwright-cli list                     # вывести список всех сессий
```

Вы можете настроить своего агента программирования на использование определённой сессии:

```bash
PLAYWRIGHT_CLI_SESSION=todo-app claude .
```

### Управление сессиями

```bash
playwright-cli list                     # вывести список всех сессий
playwright-cli close-all                # закрыть все браузеры
playwright-cli kill-all                 # принудительно завершить все процессы браузеров
playwright-cli -s=name delete-data      # удалить пользовательские данные именованной сессии
```

Сессия в режиме без графического интерфейса автоматически завершается после часа без команд, поэтому сессия, которую агент забыл закрыть, не оставляет браузер работающим. Браузеры с графическим интерфейсом и браузеры, к которым выполнено подключение, никогда не закрываются автоматически. Измените время ожидания с помощью `open --idle-timeout=<ms>` или `timeouts.idle` в файле конфигурации; передайте `0`, чтобы отключить автоматическое завершение.

## Мониторинг

Используйте `playwright-cli show`, чтобы открыть визуальную панель для наблюдения за всеми запущенными сессиями браузера и управления ими:

```bash
playwright-cli show
```

Панель предоставляет следующие возможности:
- **Сетка сессий** — все активные сессии, сгруппированные по рабочим областям; для каждой отображаются трансляция экрана в реальном времени, имя сессии, текущий URL и заголовок страницы. Нажмите на любую сессию, чтобы развернуть её.
- **Подробный просмотр сессии** — отображение выбранной сессии в реальном времени с панелью вкладок, элементами навигации и полным дистанционным управлением. Нажмите в области просмотра, чтобы перехватить управление мышью и клавиатурой; нажмите Escape, чтобы освободить их.

## Настройка

### Режим с графическим интерфейсом

По умолчанию CLI работает без графического интерфейса. Чтобы увидеть браузер:

```bash
playwright-cli open https://playwright.dev --headed
```

### Выбор браузера

```bash
playwright-cli open --browser=chrome    # использовать определённый браузер
playwright-cli open --browser=firefox
playwright-cli open --browser=webkit
playwright-cli open --browser=msedge
```

### Файл конфигурации

Для расширенных настроек используйте файл конфигурации в формате JSON:

```bash
playwright-cli --config path/to/config.json open example.com
```

CLI также автоматически загружает `.playwright/cli.config.json`, если этот файл существует. Файл конфигурации поддерживает параметры браузера, параметры контекста, сетевые правила, тайм-ауты и многое другое. Выполните `playwright-cli --help`, чтобы получить полный список параметров.

### Расширение браузера

Подключитесь к существующим вкладкам браузера вместо запуска нового браузера:

```bash
playwright-cli attach --extension
```

Для этого необходимо установить [расширение Playwright](https://github.com/microsoft/playwright/blob/main/packages/extension/README.md).
