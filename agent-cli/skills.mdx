# Навыки

Навыки обучают агентов для написания кода эффективному использованию `playwright-cli`, предоставляя структурированную справочную документацию, которую агенты могут находить и использовать.

## Установка навыков

```bash
playwright-cli install --skills            # структура каталогов Claude Code (по умолчанию)
playwright-cli install --skills=agents     # структура каталогов .agents/skills
playwright-cli install --skills -g         # установка в домашний каталог
```

Навык копируется в `.claude/skills/playwright-cli` (или `.agents/skills/playwright-cli`) в
текущем рабочем пространстве. При использовании `--global` (псевдоним `-g`) он устанавливается в `~/.claude/skills` или `~/.agents/skills`
вместо этого, что делает его доступным в каждом проекте.

## Что предоставляют навыки

`SKILL.md` описывает набор доступных команд — основные взаимодействия, снимки и идентификаторы элементов (`ref`), сеансы, необработанный
вывод и параметры `open`/`attach` — и содержит ссылки на подробные справочные руководства по конкретным
задачам:

- **Запуск и отладка тестов Playwright** — запуск, отладка и управление наборами тестов Playwright
- **Мокирование запросов** — перехват сетевых запросов и подмена ответов на них
- **Выполнение кода Playwright** — выполнение произвольных скриптов Playwright с помощью `run-code`
- **Управление сеансами браузера** — управление несколькими сеансами браузера, подключение к ним и отключение от них
- **Состояние хранилища (cookies, localStorage)** — сохранение и восстановление состояния браузера
- **Генерация тестов** — планирование, генерация и исправление тестов Playwright
- **Трассировка** — запись и изучение трассировок выполнения
- **Запись видео** — запись видео сеансов браузера, в том числе постановочных презентационных роликов
- **Проверка атрибутов элементов** — получение атрибутов элементов, не отображаемых в снимках

## Работа без навыков

Вы можете использовать `playwright-cli` без установки навыков. Укажите агенту использовать CLI и позвольте ему самостоятельно найти доступные команды:

```txt
Протестируй сценарий «добавить задачу» на https://demo.playwright.dev/todomvc с помощью playwright-cli.
Посмотри доступные команды с помощью playwright-cli --help.
```

## Поддерживаемые агенты

Навыки работают со следующими агентами:
- Claude Code
- GitHub Copilot
- Cursor
- Любой агент для написания кода, поддерживающий локально установленные навыки
