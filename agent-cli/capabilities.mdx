# Справочник команд

Все перечисленные ниже команды доступны всегда — в отличие от [MCP](/mcp/introduction), CLI не ограничивает
доступ к отдельным возможностям. Группы соответствуют тем, которые выводятся командой `playwright-cli --help`; используйте
`playwright-cli --help <command>`, чтобы узнать точные аргументы и параметры отдельной команды.

Аргументы в `<угловых скобках>` обязательны, аргументы в `[квадратных скобках]` необязательны.

## Основные команды

| Команда | Описание |
|---------|-------------|
| `open [url]` | Открыть браузер, при необходимости перейдя по указанному URL |
| `attach [name]` | Подключиться к запущенному браузеру Playwright |
| `close` | Закрыть браузер |
| `detach` | Отключиться от подключённого браузера, оставив его работающим |
| `goto <url>` | Перейти по указанному URL |
| `type <text>` | Ввести текст в редактируемый элемент, находящийся в фокусе |
| `click <target> [button]` | Щёлкнуть по элементу |
| `dblclick <target> [button]` | Дважды щёлкнуть по элементу |
| `fill <target> <text>` | Заполнить редактируемый элемент текстом |
| `drag <startTarget> <endTarget>` | Выполнить перетаскивание между двумя элементами |
| `drop <target>` | Перетащить файлы или данные из-за пределов страницы на элемент |
| `hover <target>` | Навести указатель мыши на элемент |
| `select <target> <val>` | Выбрать вариант в раскрывающемся списке |
| `upload <files...>` | Загрузить один или несколько файлов |
| `check <target>` / `uncheck <target>` | Установить или снять флажок либо переключатель |
| `snapshot [target]` | Сделать снимок страницы, чтобы получить идентификаторы элементов |
| `find [text]` | Выполнить поиск по снимку страницы и вернуть совпадения с контекстом |
| `eval <func> [target]` | Выполнить JavaScript на странице или для элемента |
| `dialog-accept [prompt]` / `dialog-dismiss` | Обработать диалоговое окно |
| `resize <w> <h>` | Изменить размер окна браузера |
| `delete-data` | Удалить пользовательские данные сеанса |

См. разделы [Взаимодействие](./commands/interaction.mdx), [Навигация](./commands/navigation.mdx) и
[Диалоговые окна](./commands/dialogs.mdx).

## Навигация

| Команда | Описание |
|---------|-------------|
| `go-back` | Вернуться на предыдущую страницу |
| `go-forward` | Перейти вперёд на следующую страницу |
| `reload` | Перезагрузить текущую страницу |

## Клавиатура

| Команда | Описание |
|---------|-------------|
| `press <key>` | Нажать клавишу, например `Enter` или `ArrowLeft` |
| `keydown <key>` / `keyup <key>` | Нажать и удерживать клавишу или отпустить её |

## Мышь

Взаимодействие по координатам с использованием позиций в пикселях на снимках экрана. Полезно для приложений на основе canvas, карт
и пользовательских виджетов без элементов, доступных через средства специальных возможностей.

| Команда | Описание |
|---------|-------------|
| `mousemove <x> <y>` | Переместить указатель мыши в указанные координаты |
| `mousedown [button]` / `mouseup [button]` | Нажать или отпустить кнопку мыши |
| `mousewheel <dx> <dy>` | Выполнить прокрутку колёсиком мыши |

См. раздел [Режим визуального взаимодействия](./vision-mode.mdx).

## Сеть

| Команда | Описание |
|---------|-------------|
| `requests` | Вывести список сетевых запросов с номерами для использования в команде `request` |
| `request <index>` | Вывести полные сведения об отдельном запросе |
| `request-headers <index>` / `request-body <index>` | Вывести отдельную часть запроса |
| `response-headers <index>` / `response-body <index>` | Вывести отдельную часть ответа |
| `route <pattern>` | Подменить ответы на запросы, соответствующие шаблону URL |
| `route-list` | Вывести список активных маршрутов |
| `unroute [pattern]` | Удалить соответствующие шаблону маршруты или все маршруты |
| `network-state-set <state>` | Перевести браузер в режим с подключением к сети или без него |

См. раздел [Сеть и подмена ответов](./commands/network-routing.mdx).

## Глобальные параметры

Эти параметры применимы ко всем командам и могут располагаться в любом месте командной строки.

| Параметр | Описание |
|--------|-------------|
| `-s=<name>`, `--session=<name>` | Выполнить команду в именованном сеансе браузера |
| `--raw` | Вывести только значение результата, без состояния страницы, сгенерированного кода или снимка |
| `--json` | Представить весь ответ в формате JSON |
| `--help [command]` | Вывести справку |
| `--version` | Вывести версию |

```bash
# передать значение напрямую в другой инструмент через канал
playwright-cli --raw eval "JSON.stringify(performance.timing)" | jq '.loadEventEnd - .navigationStart'
playwright-cli --raw snapshot > before.yml

# структурированный вывод для использования в скриптах
playwright-cli list --json
```
