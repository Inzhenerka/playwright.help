# Быстрый старт

## Интерактивная демонстрация

Попробуйте дать своему агенту для написания кода такое задание:

```txt
Используй навыки playwright для тестирования https://demo.playwright.dev/todomvc/.
Сделай скриншоты для всех успешных и неуспешных сценариев.
```

## Пошаговое выполнение вручную

Выполните команды вручную, чтобы увидеть, как работает CLI:

```bash
playwright-cli open https://demo.playwright.dev/todomvc/ --headed
playwright-cli type "Buy groceries"
playwright-cli press Enter
playwright-cli type "Water flowers"
playwright-cli press Enter
playwright-cli check e21
playwright-cli screenshot
playwright-cli close
```

## Как читать вывод

После каждой команды CLI выводит снимок текущего состояния страницы:

```txt
### Page
- Page URL: https://demo.playwright.dev/todomvc/#/
- Page Title: React - TodoMVC
### Snapshot
- [Snapshot](.playwright-cli/page-2026-02-14T19-22-42-679Z.yml)
```

Файл снимка содержит дерево доступности с идентификаторами элементов (`ref`), которые можно использовать в последующих командах.

## Основной рабочий процесс

Каждое взаимодействие следует этой схеме:

1. **Открытие** — `playwright-cli open <url>` открывает указанный URL
2. **Снимок** — каждая команда возвращает дерево доступности с идентификаторами элементов
3. **Взаимодействие** — используйте идентификаторы для нажатий, ввода текста или заполнения полей
4. **Повторный снимок** — каждое действие возвращает обновлённое состояние с новыми идентификаторами

На большой странице команда `find` требует меньше ресурсов, чем полный снимок, если вам нужен только один элемент:

```bash
playwright-cli find "Sign in"
playwright-cli find --regex "/sign (in|up)/i"
```

## Получение справки

```bash
playwright-cli --help                # все команды, сгруппированные по категориям
playwright-cli --help screenshot     # аргументы и параметры одной команды
```
