# Вкладки

| Команда | Описание |
|---------|-------------|
| `tab-list` | Вывести список всех открытых вкладок |
| `tab-new [url]` | Открыть новую вкладку |
| `tab-select <index>` | Переключиться на вкладку по индексу |
| `tab-close [index]` | Закрыть вкладку |

## Просмотр списка вкладок

```bash
$ playwright-cli tab-list
### Open tabs
- 0: (current) [React - TodoMVC](https://demo.playwright.dev/todomvc/)
- 1: [Example Domain](https://example.com/)
- 2: [Google](https://google.com/)
```

Раздел `Open tabs` также автоматически включается в вывод любой команды, когда открыто более
одной вкладки или когда набор вкладок изменяется.

## Создание вкладок

```bash
playwright-cli tab-new                  # пустая вкладка
playwright-cli tab-new https://example.com  # сразу перейти по адресу
```

## Переключение между вкладками

```bash
playwright-cli tab-select 1             # переключиться на вторую вкладку
playwright-cli tab-select 0             # вернуться на первую
```

## Закрытие вкладок

```bash
playwright-cli tab-close                # закрыть текущую вкладку
playwright-cli tab-close 2              # закрыть указанную вкладку
```

## Рабочий процесс: сравнение страниц

```bash
playwright-cli open https://staging.example.com
playwright-cli snapshot --filename=staging.yaml
playwright-cli tab-new https://example.com
playwright-cli snapshot --filename=production.yaml
# Агент сравнивает два снимка
```
