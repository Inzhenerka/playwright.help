# Скриншоты и PDF

## Скриншоты

| Команда | Описание |
|---------|-------------|
| `screenshot` | Скриншот области просмотра |
| `screenshot [target]` | Скриншот определённого элемента |
| `screenshot --filename=<f>` | Сохранение с указанным именем файла |
| `screenshot --type=<png\|jpeg\|webp>` | Формат изображения |
| `screenshot --full-page` | Вся прокручиваемая страница вместо области просмотра |
| `screenshot --hires` | Захват в пикселях устройства вместо CSS-пикселей |

Без `--filename` файл сохраняется в выходном каталоге с именем `page-{timestamp}.{png|jpeg|webp}`.
Если `--type` не указан, формат определяется по расширению имени файла; по умолчанию используется PNG.

```bash
$ playwright-cli screenshot
# Скриншот сохранён в .playwright-cli/page-2026-03-15T10-22-01-118Z.png

$ playwright-cli screenshot e15
# Скриншот элемента e15

$ playwright-cli screenshot --filename=login-page.png
$ playwright-cli screenshot --full-page --filename=full-page.png
$ playwright-cli screenshot --filename=preview.jpeg
$ playwright-cli screenshot --hires --filename=retina.png
```

`--hires` учитывает коэффициент плотности пикселей устройства, благодаря чему текст на скриншоте
остаётся разборчивым при проверке дизайна, — однако координаты пикселей на нём уже не совпадают с координатами в CSS-пикселях,
которые принимают [команды мыши](./keyboard-mouse.mdx).

## Экспорт в PDF

```bash
playwright-cli pdf                      # сохранить как page-{timestamp}.pdf
playwright-cli pdf --filename=page.pdf  # сохранить с указанным именем
```

## Когда использовать скриншоты

Скриншоты дополняют снимки дерева доступности:

| Сценарий использования | Лучший инструмент |
|----------|-----------|
| Взаимодействие с элементами | Идентификаторы элементов из снимка дерева доступности |
| Проверка визуального расположения элементов | Скриншот |
| Содержимое canvas и диаграмм | Скриншот |
| Документирование ошибки | Скриншот |
| Изучение структуры страницы | Снимок дерева доступности |
| Чтение текстового содержимого | Снимок дерева доступности |

## Снимки дерева доступности

Для вывода дерева доступности (а не визуального снимка):

```bash
playwright-cli snapshot                 # снимок всей страницы
playwright-cli snapshot --filename=f    # указанное имя файла
playwright-cli snapshot [target]        # снимок элемента
playwright-cli snapshot --depth=N       # ограничить глубину
playwright-cli snapshot --boxes         # включить ограничивающие прямоугольники
playwright-cli find "text"              # поиск вместо создания снимка
```

Подробнее о формате и использовании см. в разделе [Снимки дерева доступности](../snapshots.mdx).
