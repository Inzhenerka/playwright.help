# Клавиатура и мышь

## Клавиатура

| Команда | Описание |
|---------|-------------|
| `press <key>` | Нажать клавишу (например, `Enter`, `ArrowLeft`, `a`) |
| `keydown <key>` | Нажать и удерживать клавишу |
| `keyup <key>` | Отпустить клавишу |
| `type <text>` | Ввести текст посимвольно в элемент, находящийся в фокусе |

### Часто используемые клавиши

`Enter`, `Tab`, `Escape`, `Backspace`, `Delete`, `Space`,
`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`,
`Home`, `End`, `PageUp`, `PageDown`

### Сочетания клавиш

```bash
playwright-cli press Control+a          # выделить всё
playwright-cli press Control+c          # скопировать
playwright-cli press Control+v          # вставить
playwright-cli press Shift+Tab          # перейти к предыдущему элементу
playwright-cli press Alt+Enter          # alt+enter
```

Команды `keydown` / `keyup` позволяют удерживать клавишу-модификатор при выполнении нескольких команд, чего нельзя сделать с помощью `press`:

```bash
playwright-cli keydown Shift
playwright-cli click e5
playwright-cli click e9                 # расширяет выделение
playwright-cli keyup Shift
```

Чтобы удерживать клавиши-модификаторы при одном щелчке, проще использовать `click --modifiers` — см.
[Взаимодействие](./interaction.mdx).

### Навигация с помощью клавиатуры

```bash
playwright-cli press Tab                # следующее поле
playwright-cli press Tab                # следующее поле
playwright-cli press ArrowDown          # перемещение по раскрывающемуся списку
playwright-cli press ArrowDown
playwright-cli press Enter              # выбрать вариант
```

## Мышь

| Команда | Описание |
|---------|-------------|
| `mousemove <x> <y>` | Переместить указатель мыши в заданные координаты |
| `mousedown [button]` | Нажать и удерживать кнопку мыши (left — левая, right — правая, middle — средняя) |
| `mouseup [button]` | Отпустить кнопку мыши |
| `mousewheel <dx> <dy>` | Выполнить прокрутку (dx — по горизонтали, dy — по вертикали) |

Координаты задаются в CSS-пикселях относительно области просмотра. Команда `snapshot --boxes` выводит границы каждого элемента в той же
системе координат, что удобнее, чем определять положение элементов по снимку экрана.

```bash
# Щелчок по заданным координатам
playwright-cli mousemove 100 200
playwright-cli mousedown
playwright-cli mouseup

# Щелчок правой кнопкой мыши
playwright-cli mousemove 300 400
playwright-cli mousedown right
playwright-cli mouseup right

# Прокрутка вниз на 500 пикселей
playwright-cli mousewheel 0 500

# Прокрутка вправо на 200 пикселей
playwright-cli mousewheel 200 0
```

### Когда использовать команды мыши

| Сценарий | Рекомендуемый подход |
|----------|---------------------|
| Щелчок по кнопке, ссылке или элементу формы | `click`, `fill` и другие команды, использующие идентификаторы элементов (`ref`) |
| Приложения на основе canvas (рисование, карты) | Команды мыши с указанием координат |
| Пользовательские элементы интерфейса без поддержки доступности | Команды мыши с указанием координат |
| Перетаскивание объектов, требующее точности до пикселя | Команды мыши с указанием координат |

Для большинства веб-приложений **идентификаторы элементов (`ref`) из снимков дерева доступности надёжнее**, чем координаты. Используйте команды мыши только тогда, когда нужные элементы не представлены в дереве доступности.
