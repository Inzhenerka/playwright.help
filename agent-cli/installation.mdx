# Установка

## Предварительные требования

- [Node.js](https://nodejs.org/) версии 20 или новее
- Агент для написания кода: Claude Code, GitHub Copilot или аналогичный

## Глобальная установка

```bash
npm install -g @playwright/cli@latest
playwright-cli --help
```

## Использование версии из вашего проекта

Если Playwright уже указан в зависимостях проекта, CLI доступен через него — глобальная
установка не требуется:

```bash
npx --no-install playwright --version   # проверьте, что Playwright установлен локально
npx playwright cli --help
```

Везде, где в этой документации указано `playwright-cli <command>`, команда `npx playwright cli <command>` работает
точно так же.

## Инициализация рабочего пространства

```bash
playwright-cli install
```

Эта команда создаёт каталог `.playwright` в текущем рабочем каталоге, добавляет его в `.gitignore`
и загружает настроенный браузер, если он отсутствует.

## Установка навыков

Агенты для написания кода, такие как Claude Code и GitHub Copilot, используют локально установленные навыки (skills), чтобы получать более подробный контекст
о доступных командах и рабочих процессах:

```bash
playwright-cli install --skills            # то же, что и --skills=claude
playwright-cli install --skills=claude     # .claude/skills/playwright-cli
playwright-cli install --skills=agents     # .agents/skills/playwright-cli
playwright-cli install --skills -g         # установить в домашний каталог
```

`--global` (псевдоним `-g`) устанавливает навык в `~/.claude/skills` или `~/.agents/skills`, чтобы он был
доступен в каждом проекте. Этот параметр требует указания `--skills` и пропускает инициализацию рабочего пространства.

Подробнее о содержимом навыка см. в разделе [Навыки](./skills.mdx).

## Установка браузеров

CLI автоматически загружает браузер при первом использовании. Чтобы установить его явно:

```bash
playwright-cli install-browser               # установить браузеры, необходимые этой версии
playwright-cli install-browser firefox       # установить один конкретный браузер
playwright-cli install-browser --with-deps   # установить вместе с системными зависимостями
```

### Параметры установки

| Флаг | Описание |
|------|-------------|
| `--with-deps` | Установить системные зависимости (Linux) |
| `--dry-run` | Предварительно показать, что будет установлено |
| `--list` | Вывести список доступных браузеров из всех установок |
| `--force` | Принудительно переустановить, даже если браузер уже установлен |
| `--only-shell` | Установить только Chromium headless shell |
| `--no-shell` | Пропустить установку Chromium headless shell |

## Работа без навыков

Вы также можете напрямую указать агенту использовать CLI и позволить ему самостоятельно найти доступные команды:

```txt
Протестируй сценарий «добавить задачу» на https://demo.playwright.dev/todomvc с помощью playwright-cli.
Посмотри доступные команды с помощью playwright-cli --help.
```

## Настройка окружения

Настройте агент для написания кода на использование определённой сессии:

```bash
PLAYWRIGHT_CLI_SESSION=todo-app claude .
```
