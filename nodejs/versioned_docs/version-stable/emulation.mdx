## Введение {#introduction}

С помощью Playwright вы можете тестировать ваше приложение в любом браузере, а также эмулировать реальное устройство, такое как мобильный телефон или планшет. Просто настройте устройства, которые вы хотите эмулировать, и Playwright будет симулировать поведение браузера, такое как `"userAgent"`, `"screenSize"`, `"viewport"` и наличие поддержки `"hasTouch"`. Вы также можете эмулировать `"geolocation"`, `"locale"` и `"timezone"` для всех тестов или для конкретного теста, а также установить `"permissions"` для показа уведомлений или изменения `"colorScheme"`.

## Устройства {#devices}

Playwright поставляется с [реестром параметров устройств](https://github.com/microsoft/playwright/blob/main/packages/isomorphic/deviceDescriptorsSource.json), доступным через [playwright.devices](/api/class-playwright.mdx#playwright-devices), для ряда настольных компьютеров, планшетов и мобильных устройств. Его можно использовать для имитации поведения браузера на конкретном устройстве, задавая такие параметры, как пользовательский агент (user agent), размер экрана, область просмотра и поддержка сенсорного ввода. Все тесты будут выполняться с указанными параметрами устройства.


**Примечание**: Предварительно настроенные устройства предполагают использование определённой платформы. Например, "Desktop Chrome" задаёт строку User-Agent, характерную для Windows.

Если вы хотите использовать User-Agent, соответствующий платформе, на которой запускаются тесты, рекомендуем сбросить значение свойства `userAgent`.

```js
const context = await browser.newContext({
  ...devices['Desktop Chrome'],
  userAgent: undefined,
});
```

## Вьюпорт (Viewport) {#viewport}

Viewport включен в устройство, но вы можете переопределить его для некоторых тестов с помощью [page.setViewportSize()](/api/class-page.mdx#page-set-viewport-size).

  defaultValue="test"
  values={[
    {label: 'Test', value: 'test'},

  ]
}>
<TabItem value="test">

```js title="playwright.config.ts"
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  projects: [
    {
      name: 'chromium',
      use: {
        ...devices['Desktop Chrome'],
        // Важно определить свойство `viewport` после деструктуризации `devices`,
        // так как устройства также определяют `viewport` для этого устройства.
        viewport: { width: 1280, height: 720 },
      },
    },
  ]
});
```

</TabItem>

## Локаль и Часовой пояс {#locale-timezone}

Эмулируйте локаль и часовой пояс браузера: их можно задать глобально для всех тестов в конфиге, а затем переопределять для отдельных тестов.

```js title="playwright.config.ts"
import { defineConfig } from '@playwright/test';

export default defineConfig({
  use: {
    // Эмулирует локаль браузера.
    locale: 'en-GB',

    // Эмулирует часовой пояс браузера.
    timezoneId: 'Europe/Paris',
  },
});
```

## Цветовая схема и медиа {#color-scheme-and-media}

Эмулирует пользовательскую настройку `"colorScheme"`. Поддерживаемые значения: 'light', 'dark' и 'no-preference'. Вы также можете эмулировать тип медиа с помощью [page.emulateMedia()](/api/class-page.mdx#page-emulate-media).

```js title="playwright.config.ts"
import { defineConfig } from '@playwright/test';

export default defineConfig({
  use: {
    colorScheme: 'dark',
  },
});
```

  groupId="js-flavor"
  defaultValue="test"
  values={[
    {label: 'Test', value: 'test'},
    {label: 'Library', value: 'library'}
  ]
}>
<TabItem value="test">

```js title="tests/example.spec.ts"
import { test, expect } from '@playwright/test';

test.use({
  colorScheme: 'dark' // или 'light'
});

test('my test with dark mode', async ({ page }) => {
  // ...
});
```

</TabItem>
<TabItem value="library">

```js
// Создать контекст с темным режимом
const context = await browser.newContext({
  colorScheme: 'dark' // или 'light'
});

// Создать страницу с темным режимом
const page = await browser.newPage({
  colorScheme: 'dark' // или 'light'
});

// Изменить цветовую схему для страницы
await page.emulateMedia({ colorScheme: 'dark' });

// Изменить медиа для страницы
await page.emulateMedia({ media: 'print' });
```

</TabItem>
</Tabs>

<img height="1824" width="2788" alt="сайт Playwright в тёмном режиме" src="https://user-images.githubusercontent.com/13063165/220411638-55d2b051-4678-4da7-9f0b-ed22f5a3c47c.png" />

Параметры `"reducedMotion"`, `"forcedColors"` и `"contrast"` аналогичным образом эмулируют медиафункции `prefers-reduced-motion`, `forced-colors` и `prefers-contrast`. Поддерживаемые значения: `'reduce'` и `'no-preference'` для уменьшения анимации, `'active'` и `'none'` для принудительных цветов, а также `'more'` и `'no-preference'` для контрастности. Метод [page.emulateMedia()](/api/class-page.mdx#page-emulate-media) изменяет их для отдельной страницы.

```js title="playwright.config.ts"
import { defineConfig } from '@playwright/test';

export default defineConfig({
  use: {
    reducedMotion: 'reduce',
    forcedColors: 'active',
    contrast: 'more',
  },
});
```

## Офлайн {#offline}

Эмулируйте отключение сети.

```js title="playwright.config.ts"
import { defineConfig } from '@playwright/test';

export default defineConfig({
  use: {
    offline: true
  },
});
```

:::note
Эмуляция автономного режима влияет только на запросы, проходящие через стандартный сетевой стек браузера, такие как переходы между страницами, `fetch()`, `XMLHttpRequest` и WebSockets. Она не влияет на трафик WebRTC: установленные соединения `RTCPeerConnection` продолжают отправлять и получать медиаданные по UDP. Чтобы протестировать потерю соединения WebRTC, прервите соединение за пределами браузера, например остановив TURN-сервер или используя брандмауэр на уровне ОС.
:::
