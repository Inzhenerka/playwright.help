### showActions {/* #screencast-show-actions */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showActions</x-search>

Включает визуальные аннотации для элементов, с которыми выполняется взаимодействие. Возвращает объект Disposable, при освобождении которого отображение действий прекращается.

**Использование**

```js
await screencast.showActions();
await screencast.showActions(options);
```

**Аргументы**
- `options` [Object] *(необязательно)*
  - `cursor` "none" | "pointer" *(необязательно)* <font size="2">Добавлено в: v1.61</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-cursor"/><a href="#screencast-show-actions-option-cursor" class="list-anchor">#</a>
    
    Визуальное обозначение курсора, отображаемое при действиях указателя. Значение `"pointer"` (по умолчанию) отображает указатель мыши, который анимированно перемещается от точки предыдущего действия к точке следующего. Значение `"none"` отключает визуальное обозначение курсора.
  - `duration` [number] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-duration"/><a href="#screencast-show-actions-option-duration" class="list-anchor">#</a>
    
    Продолжительность отображения каждой аннотации в миллисекундах. По умолчанию — `500`.
  - `fontSize` [number] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-font-size"/><a href="#screencast-show-actions-option-font-size" class="list-anchor">#</a>
    
    :::warning[Устарело]
    Вместо этого используйте `title` в [style](/api/class-screencast.mdx#screencast-show-actions-option-style), например `style: { title: 'font-size: 32px' }`.
    :::
    
    
    Размер шрифта заголовка действия в пикселях. По умолчанию — `24`.
  - `position` "top-left" | "top" | "top-right" | "bottom-left" | "bottom" | "bottom-right" *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-position"/><a href="#screencast-show-actions-option-position" class="list-anchor">#</a>
    
    Положение оверлея с заголовком действия. По умолчанию — `"top-right"`.
  - `style` [Object] *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-style"/><a href="#screencast-show-actions-option-style" class="list-anchor">#</a>
    - `point` [string] *(необязательно)*
      
      CSS-объявления для маркера в точке действия. Маркер располагается в точке действия, имеет нулевой размер и центрируется относительно этой точки, поэтому его размер и внешний вид определяются этим стилем. Если параметр не указан, маркер не отображается.
    - `highlight` [string] *(необязательно)*
      
      CSS-объявления для прямоугольной области, покрывающей целевой элемент. Положение и размер этой области соответствуют границам элемента. Если параметр не указан, область не отображается.
    - `title` [string] *(необязательно)*
      
      CSS-объявления для заголовка действия, например `'font-size: 32px; background: #333'`. Заголовок размещается в соответствии с параметром [position](/api/class-screencast.mdx#screencast-show-actions-option-position).
    
    Стили визуальных обозначений действий. Все обозначения плавно исчезают в течение времени, заданного параметром [duration](/api/class-screencast.mdx#screencast-show-actions-option-duration).
    
    **Использование**
    
    ```js
    await page.screencast.showActions({
      style: {
        point: 'width: 20px; height: 20px; border-radius: 50%; background: red',
        highlight: 'outline: 2px solid #333; background: rgba(0, 128, 255, .15)',
        title: 'font-size: 16px',
      },
    });
    ```
    
**Возвращает**
- [Promise]&lt;[Disposable]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-return"/><a href="#screencast-show-actions-return" class="list-anchor">#</a>

### showChapter {/* #screencast-show-chapter */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showChapter</x-search>

Показывает оверлей главы с заголовком и необязательным описанием по центру страницы на размытом фоне. Полезно для пояснения происходящего в видеозаписях. Оверлей удаляется по истечении указанного времени или через 2000 мс.

**Использование**

```js
await screencast.showChapter(title);
await screencast.showChapter(title, options);
```

**Аргументы**
- `title` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-title"/><a href="#screencast-show-chapter-option-title" class="list-anchor">#</a>
  
  Текст заголовка, отображаемый в оверлее в выделенном виде.
- `options` [Object] *(необязательно)*
  - `description` [string] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-description"/><a href="#screencast-show-chapter-option-description" class="list-anchor">#</a>
    
    Необязательный текст описания, отображаемый под заголовком.
  - `duration` [number] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-duration"/><a href="#screencast-show-chapter-option-duration" class="list-anchor">#</a>
    
    Время в миллисекундах, по истечении которого оверлей автоматически удаляется. По умолчанию — `2000`.

**Возвращает**
- [Promise]&lt;[void]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-return"/><a href="#screencast-show-chapter-return" class="list-anchor">#</a>

### showOverlay {/* #screencast-show-overlay */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.showOverlay</x-search>

**Использование**


  HTML-содержимое оверлея.
- `options` [Object] *(необязательно)*
  - `duration` [number] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-option-duration"/><a href="#screencast-show-overlay-option-duration" class="list-anchor">#</a>
    
    Время в миллисекундах, по истечении которого оверлей автоматически удаляется. Если параметр не указан, оверлей остается на странице до явного удаления.

**Возвращает**
- [Promise]&lt;[Disposable]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-return"/><a href="#screencast-show-overlay-return" class="list-anchor">#</a>

### start {/* #screencast-start */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.start</x-search>

Запускает скринкаст. Если указан параметр [path](/api/class-screencast.mdx#screencast-start-option-path), сохраняет видеозапись в указанный файл. Если указан параметр [onFrame](/api/class-screencast.mdx#screencast-start-option-on-frame), передает кадры в формате JPEG в функцию обратного вызова. Оба параметра можно использовать одновременно.

**Использование**

```js
// Запись видео
await page.screencast.start({ path: 'video.webm', size: { width: 1280, height: 800 } });
// ... выполнение действий ...
await page.screencast.stop();
```

```js
// Захват кадров
await page.screencast.start({
  onFrame: ({ data, timestamp, viewportWidth, viewportHeight }) => {
    console.log(`frame size: ${data.length} (${viewportWidth}x${viewportHeight}) at ${timestamp}`);
  },
  size: { width: 800, height: 600 },
});
// ... выполнение действий ...
await page.screencast.stop();
```

**Аргументы**
- `options` [Object] *(необязательно)*
  - `fps` [number] *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-fps"/><a href="#screencast-start-option-fps" class="list-anchor">#</a>
    
    Частота кадров видеозаписи в кадрах в секунду. Используется только вместе с параметром [path](/api/class-screencast.mdx#screencast-start-option-path). По умолчанию — `25`.
    
    Более высокая частота кадров делает анимацию и прокрутку плавнее, но увеличивает нагрузку на процессор при кодировании. Используйте вместе с параметром [size](/api/class-screencast.mdx#screencast-start-option-size) для записи видео высокого разрешения. Видео может содержать не больше уникальных кадров, чем создает браузер; Firefox и WebKit в настоящее время захватывают до 25 кадров в секунду.
  - `onFrame` [function]\([Object]\):[Promise] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-on-frame"/><a href="#screencast-start-option-on-frame" class="list-anchor">#</a>
    - `data` [Buffer]
      
      Данные кадра, закодированные в формате JPEG.
    - `timestamp` [number]
      
      Временная метка момента отображения кадра браузером, в миллисекундах с начала эпохи Unix.
    - `viewportWidth` [number]
      
      Ширина области просмотра страницы на момент захвата кадра.
    - `viewportHeight` [number]
      
      Высота области просмотра страницы на момент захвата кадра.
    
    Функция обратного вызова, получающая данные кадра в формате JPEG вместе с размером области просмотра страницы на момент захвата.
  - `path` [string] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-path"/><a href="#screencast-start-option-path" class="list-anchor">#</a>
    
    Путь для сохранения видео после остановки скринкаста. Если параметр указан, начинается запись видео.
  - `quality` [number] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-quality"/><a href="#screencast-start-option-quality" class="list-anchor">#</a>
    
    Качество изображения в диапазоне от 0 до 100.
  - `size` [Object] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-size"/><a href="#screencast-start-option-size" class="list-anchor">#</a>
    - `width` [number]
      
      Максимальная ширина кадра в пикселях.
    - `height` [number]
      
      Максимальная высота кадра в пикселях.
    
    Задает размеры кадров скринкаста. Фактический кадр масштабируется с сохранением соотношения сторон страницы и может быть меньше указанных размеров. Если скринкаст уже активен (например, запущен при трассировке или записи видео), существующая конфигурация имеет приоритет, и размер кадра может превышать эти ограничения либо этот параметр может игнорироваться. Если параметр не указан, размер будет равен размеру области просмотра страницы, уменьшенному так, чтобы он вписывался в 800×800.

**Возвращает**
- [Promise]&lt;[Disposable]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-return"/><a href="#screencast-start-return" class="list-anchor">#</a>
