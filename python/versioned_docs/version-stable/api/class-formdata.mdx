## Методы

### append {/* #form-data-append */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.44</font><x-search>formData.append</x-search>

Добавляет новое значение к существующему ключу в объекте FormData или добавляет ключ, если он ещё не существует. Файлы можно передавать как `Path` или как `FilePayload`. Можно добавлять несколько полей с одинаковым именем.

Разница между [form_data.set()](/api/class-formdata.mdx#form-data-set) и [form_data.append()](/api/class-formdata.mdx#form-data-append) заключается в том, что, если указанный ключ уже существует, [form_data.set()](/api/class-formdata.mdx#form-data-set) заменит все существующие значения новым, тогда как [form_data.append()](/api/class-formdata.mdx#form-data-append) добавит новое значение в конец существующего набора значений.

<Tabs
  groupId="python-flavor"
  defaultValue="sync"
  values={[
    {label: 'Sync', value: 'sync'},
    {label: 'Async', value: 'async'}
  ]
}>
<TabItem value="sync">

```py
form = FormData()
# Задаются только имя и значение.
form.append("firstName", "John")
# Задаются имя и значение, имя файла и Content-Type определяются по пути к файлу.
form.append("attachment", Path("pic.jpg"))
# Задаются имя, значение, имя файла и Content-Type.
form.append("attachment", {
    "name": "table.csv",
    "mimeType": "text/csv",
    "buffer": Path("my-table.csv").read_bytes(),
})
page.request.post("http://localhost/submit", multipart=form)
```

</TabItem>

### set {/* #form-data-set */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.18</font><x-search>formData.set</x-search>

Задаёт значение поля формы. Файлы можно передавать как `Path` или как `FilePayload`.
