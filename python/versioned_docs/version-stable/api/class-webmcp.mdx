[WebMCP] предоставляет доступ к инструментам, которые фрейм регистрирует через экспериментальный браузерный API [WebMCP](https://webmachinelearning.github.io/webmcp/), `navigator.modelContext`. Он позволяет получать список инструментов и вызывать их.

Доступ к экземплярам осуществляется через [frame.webmcp](/api/class-frame.mdx#frame-webmcp). [page.webmcp](/api/class-page.mdx#page-webmcp) — это экземпляр для главного фрейма.

:::note

WebMCP — экспериментальная функция браузера. В Chromium она включается с помощью аргумента запуска `--enable-features=WebMCP`, а в Firefox — с помощью настроек `dom.modelcontext.enabled` и `dom.modelcontext.testing.enabled`. В WebKit она не реализована.
:::

Названия инструментов, их описания, схемы входных данных и результаты предоставляются страницей, поэтому рассматривайте их как недоверенные входные данные.

## Методы

### call_tool {/* #web-mcp-call-tool */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.64</font><x-search>webMCP.call_tool</x-search>

Вызывает инструмент, зарегистрированный фреймом, и возвращает результат его выполнения. Результатом является значение, которое возвращает функция `execute` инструмента после завершения, обычно это объект с массивом `content`. Результат с `isError: true` возвращается без изменений. Метод выбрасывает исключение, если инструмент не зарегистрирован или его функция `execute` выбрасывает исключение.

**Использование**

```python
web_mcp.call_tool(name)
web_mcp.call_tool(name, **kwargs)
```

**Аргументы**
- `name` [str]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-name"/><a href="#web-mcp-call-tool-option-name" class="list-anchor">#</a>
  
  Название инструмента, возвращаемое методом [web_mcp.tools()](/api/class-webmcp.mdx#web-mcp-tools).
- `input` [Dict] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-input"/><a href="#web-mcp-call-tool-option-input" class="list-anchor">#</a>
  
  Входные данные для инструмента, соответствующие его `inputSchema`. По умолчанию используется пустой объект.
- `timeout` [float] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-timeout"/><a href="#web-mcp-call-tool-option-timeout" class="list-anchor">#</a>
  
  Максимальное время ожидания в миллисекундах. По умолчанию — `30000` (30 секунд). Передайте `0`, чтобы отключить тайм-аут. Значение по умолчанию можно изменить с помощью методов [browser_context.set_default_timeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) или [page.set_default_timeout()](/api/class-page.mdx#page-set-default-timeout).

**Возвращаемое значение**
- [Dict]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-return"/><a href="#web-mcp-call-tool-return" class="list-anchor">#</a>

### tools {/* #web-mcp-tools */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.64</font><x-search>webMCP.tools</x-search>

Возвращает инструменты, зарегистрированные фреймом на данный момент. Выбрасывает исключение, если браузер запущен без поддержки WebMCP. Параметры запуска, включающие эту поддержку, приведены в примечании выше.

[page.webmcp](/api/class-page.mdx#page-webmcp) охватывает только главный фрейм; дочерние фреймы предоставляют список своих инструментов через собственный экземпляр [frame.webmcp](/api/class-frame.mdx#frame-webmcp).

**Использование**

```python
web_mcp.tools()
web_mcp.tools(**kwargs)
```

**Аргументы**
- `timeout` [float] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-option-timeout"/><a href="#web-mcp-tools-option-timeout" class="list-anchor">#</a>
  
  Максимальное время ожидания в миллисекундах. По умолчанию — `30000` (30 секунд). Передайте `0`, чтобы отключить тайм-аут. Значение по умолчанию можно изменить с помощью методов [browser_context.set_default_timeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) или [page.set_default_timeout()](/api/class-page.mdx#page-set-default-timeout).

**Возвращаемое значение**
- [List]\[[Dict]\]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-return"/><a href="#web-mcp-tools-return" class="list-anchor">#</a>
  - `name` [str]
    
    Название инструмента, уникальное в пределах фрейма.
  - `description` [str]
    
    Описание инструмента.
  - `inputSchema` [Dict] *(необязательно)*
    
    Схема JSON Schema входных данных инструмента, если страница её предоставляет.
  - `annotations` [Dict] *(необязательно)*
    - `readOnly` [bool] *(необязательно)*
      
      Инструмент не изменяет никакое состояние.
    - `untrustedContent` [bool] *(необязательно)*
      
      Выходные данные инструмента могут содержать сторонний контент.
    - `consequential` [bool] *(необязательно)*
      
      Инструмент выполняет действие, имеющее значимые последствия, например размещение заказа.
    
    Подсказки об инструменте, предоставляемые страницей.
