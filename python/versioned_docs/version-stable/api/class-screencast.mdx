### show_actions {/* #screencast-show-actions */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.show_actions</x-search>

Включает визуальные аннотации на элементах, с которыми выполняется взаимодействие. Возвращает объект Disposable, при освобождении которого отображение действий прекращается.

**Использование**

```python
screencast.show_actions()
screencast.show_actions(**kwargs)
```

**Аргументы**
- `cursor` "none" | "pointer" *(необязательно)* <font size="2">Добавлено в: v1.61</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-cursor"/><a href="#screencast-show-actions-option-cursor" class="list-anchor">#</a>
  
  Визуальное обозначение курсора для действий указателя. Значение `"pointer"` (по умолчанию) отображает указатель мыши, который анимированно перемещается от точки предыдущего действия к точке следующего. Значение `"none"` отключает визуальное обозначение курсора.
- `duration` [float] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-duration"/><a href="#screencast-show-actions-option-duration" class="list-anchor">#</a>
  
  Время отображения каждой аннотации в миллисекундах. По умолчанию — `500`.
- `font_size` [int] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-font-size"/><a href="#screencast-show-actions-option-font-size" class="list-anchor">#</a>
  
  :::warning[Устарело]
  Вместо этого используйте `title` в [style](/api/class-screencast.mdx#screencast-show-actions-option-style), например `style: { title: 'font-size: 32px' }`.
  :::
  
  
  Размер шрифта заголовка действия в пикселях. По умолчанию — `24`.
- `position` "top-left" | "top" | "top-right" | "bottom-left" | "bottom" | "bottom-right" *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-position"/><a href="#screencast-show-actions-option-position" class="list-anchor">#</a>
  
  Положение наложения с заголовком действия. По умолчанию — `"top-right"`.
- `style` [Dict] *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-style"/><a href="#screencast-show-actions-option-style" class="list-anchor">#</a>
  - `point` [str] *(необязательно)*
    
    CSS-объявления для маркера в точке действия. Маркер располагается в точке действия, имеет нулевой размер и центрируется относительно этой точки, поэтому его размер и внешний вид задаются этим стилем. Если параметр не указан, маркер не отображается.
  - `highlight` [str] *(необязательно)*
    
    CSS-объявления для прямоугольника, покрывающего целевой элемент. Положение и размеры прямоугольника соответствуют границам элемента. Если параметр не указан, прямоугольник не отображается.
  - `title` [str] *(необязательно)*
    
    CSS-объявления для заголовка действия, например `'font-size: 32px; background: #333'`. Заголовок размещается в соответствии с [position](/api/class-screencast.mdx#screencast-show-actions-option-position).
  
  Стили визуальных обозначений действий. Все обозначения постепенно исчезают в течение [duration](/api/class-screencast.mdx#screencast-show-actions-option-duration).
  
  **Использование**
  
  ```js
  await page.screencast.showActions({
    style: {
      point: 'width: 20px; height: 20px; border-radius: 50%; background: red',
      highlight: 'outline: 2px solid #333; background: rgba(0, 128, 255, .15)',
      title: 'font-size: 16px',
    },
  });
  ```
  
**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-return"/><a href="#screencast-show-actions-return" class="list-anchor">#</a>

### show_chapter {/* #screencast-show-chapter */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.show_chapter</x-search>

Показывает наложение главы с заголовком и необязательным описанием по центру страницы с размытым фоном. Полезно для сопровождения видеозаписей пояснениями. Наложение удаляется по истечении указанного времени или через 2000 мс.

**Использование**

```python
screencast.show_chapter(title)
screencast.show_chapter(title, **kwargs)
```

**Аргументы**
- `title` [str]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-title"/><a href="#screencast-show-chapter-option-title" class="list-anchor">#</a>
  
  Текст заголовка, выделенный на наложении.
- `description` [str] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-description"/><a href="#screencast-show-chapter-option-description" class="list-anchor">#</a>
  
  Необязательный текст описания, отображаемый под заголовком.
- `duration` [float] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-duration"/><a href="#screencast-show-chapter-option-duration" class="list-anchor">#</a>
  
  Время в миллисекундах, по истечении которого наложение автоматически удаляется. По умолчанию — `2000`.

**Возвращает**
- [NoneType]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-return"/><a href="#screencast-show-chapter-return" class="list-anchor">#</a>

  Время в миллисекундах, по истечении которого наложение автоматически удаляется. Если параметр не указан, наложение остаётся до явного удаления.

### start {/* #screencast-start */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.start</x-search>

Запускает скринкаст. Если указан [path](/api/class-screencast.mdx#screencast-start-option-path), сохраняет видеозапись в заданный файл. Если указан [on_frame](/api/class-screencast.mdx#screencast-start-option-on-frame), передаёт кадры в формате JPEG в функцию обратного вызова. Оба параметра можно использовать одновременно.

**Использование**

**Аргументы**
- `fps` [int] *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-fps"/><a href="#screencast-start-option-fps" class="list-anchor">#</a>
  
  Частота кадров видеозаписи в кадрах в секунду. Используется только вместе с [path](/api/class-screencast.mdx#screencast-start-option-path). По умолчанию — `25`.
  
  Более высокая частота кадров делает анимации и прокрутку плавнее, но увеличивает нагрузку на процессор при кодировании. Используйте вместе с [size](/api/class-screencast.mdx#screencast-start-option-size) для записи видео высокого разрешения. Видео может содержать лишь столько различных кадров, сколько создаёт браузер; Firefox и WebKit в настоящее время захватывают до 25 кадров в секунду.
- `on_frame` [Callable]\[[Dict]\]:[Promise] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-on-frame"/><a href="#screencast-start-option-on-frame" class="list-anchor">#</a>
  - `data` [bytes]
    
    Данные кадра, закодированные в формате JPEG.
  - `timestamp` [float]
    
    Временная метка момента отображения кадра браузером, в миллисекундах с начала эпохи Unix.
  - `viewportWidth` [int]
    
    Ширина области просмотра страницы на момент захвата кадра.
  - `viewportHeight` [int]
    
    Высота области просмотра страницы на момент захвата кадра.
  
  Функция обратного вызова, которая получает данные кадра в формате JPEG вместе с размерами области просмотра страницы на момент захвата.
- `path` [Union]\[[str], [pathlib.Path]\] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-path"/><a href="#screencast-start-option-path" class="list-anchor">#</a>
  
  Путь, по которому следует сохранить видео после остановки скринкаста. Если указан, запускается запись видео.
- `quality` [int] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-quality"/><a href="#screencast-start-option-quality" class="list-anchor">#</a>
  
  Качество изображения в диапазоне от 0 до 100.
- `size` [Dict] *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-size"/><a href="#screencast-start-option-size" class="list-anchor">#</a>
  - `width` [int]
    
    Максимальная ширина кадра в пикселях.
  - `height` [int]
    
    Максимальная высота кадра в пикселях.
  
  Задаёт размеры кадров скринкаста. Фактический кадр масштабируется с сохранением соотношения сторон страницы и может быть меньше указанных границ. Если скринкаст уже активен (например, запущен при трассировке или записи видео), существующая конфигурация имеет приоритет, и размер кадра может превышать эти границы либо этот параметр может игнорироваться. Если параметр не указан, размер будет равен размеру области просмотра страницы, уменьшенному так, чтобы он вписывался в 800×800.

**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-return"/><a href="#screencast-start-return" class="list-anchor">#</a>
