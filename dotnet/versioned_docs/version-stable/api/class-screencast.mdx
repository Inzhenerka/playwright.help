### ShowActionsAsync {/* #screencast-show-actions */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.ShowActionsAsync</x-search>

Включает визуальные аннотации для элементов, с которыми выполняется взаимодействие. Возвращает объект Disposable, при освобождении которого отображение действий прекращается.

**Использование**

```csharp
await Screencast.ShowActionsAsync(options);
```

**Аргументы**
- `options` `ScreencastShowActionsOptions?` *(необязательно)*
  - `Cursor` `enum ScreencastCursor { None, Pointer }?` *(необязательно)* <font size="2">Добавлено в: v1.61</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-cursor"/><a href="#screencast-show-actions-option-cursor" class="list-anchor">#</a>
    
    Визуальное обозначение курсора, отображаемое при действиях указателя. Значение `"pointer"` (по умолчанию) отображает указатель мыши, который плавно перемещается от точки предыдущего действия к точке следующего. Значение `"none"` отключает визуальное обозначение курсора.
  - `Duration` [float]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-duration"/><a href="#screencast-show-actions-option-duration" class="list-anchor">#</a>
    
    Продолжительность отображения каждой аннотации в миллисекундах. По умолчанию — `500`.
  - `FontSize` [int]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-font-size"/><a href="#screencast-show-actions-option-font-size" class="list-anchor">#</a>
    
    :::warning[Устарело]
    Вместо этого используйте `title` в [Style](/api/class-screencast.mdx#screencast-show-actions-option-style), например `style: { title: 'font-size: 32px' }`.
    :::
    
    
    Размер шрифта заголовка действия в пикселях. По умолчанию — `24`.
  - `Position` `enum AnnotatePosition { TopLeft, Top, TopRight, BottomLeft, Bottom, BottomRight }?` *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-position"/><a href="#screencast-show-actions-option-position" class="list-anchor">#</a>
    
    Положение наложения с заголовком действия. По умолчанию — `"top-right"`.
  - `Style` Style? *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-option-style"/><a href="#screencast-show-actions-option-style" class="list-anchor">#</a>
    - `Point` [string]? *(необязательно)*
      
      CSS-объявления для маркера в точке действия. Маркер располагается в точке действия, имеет нулевой размер и центрируется относительно этой точки, поэтому его размер и внешний вид определяются этим стилем. Если параметр не указан, маркер не отображается.
    - `Highlight` [string]? *(необязательно)*
      
      CSS-объявления для прямоугольника, покрывающего целевой элемент. Положение и размеры прямоугольника соответствуют границам элемента. Если параметр не указан, прямоугольник не отображается.
    - `Title` [string]? *(необязательно)*
      
      CSS-объявления для заголовка действия, например `'font-size: 32px; background: #333'`. Заголовок размещается в соответствии с [Position](/api/class-screencast.mdx#screencast-show-actions-option-position).
    
    Стили визуальных обозначений действий. Все обозначения плавно исчезают в течение времени, заданного в [Duration](/api/class-screencast.mdx#screencast-show-actions-option-duration).
    
    **Использование**
    
    ```js
    await page.screencast.showActions({
      style: {
        point: 'width: 20px; height: 20px; border-radius: 50%; background: red',
        highlight: 'outline: 2px solid #333; background: rgba(0, 128, 255, .15)',
        title: 'font-size: 16px',
      },
    });
    ```
    
**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-actions-return"/><a href="#screencast-show-actions-return" class="list-anchor">#</a>

### ShowChapterAsync {/* #screencast-show-chapter */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.ShowChapterAsync</x-search>

Показывает наложение главы с заголовком и необязательным описанием по центру страницы с размытым фоном. Полезно для пояснений в видеозаписях. Наложение удаляется по истечении указанного времени или через 2000 мс.

**Использование**

```csharp
await Screencast.ShowChapterAsync(title, options);
```

**Аргументы**
- `title` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-title"/><a href="#screencast-show-chapter-option-title" class="list-anchor">#</a>
  
  Текст заголовка, выделенный на наложении.
- `options` `ScreencastShowChapterOptions?` *(необязательно)*
  - `Description` [string]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-description"/><a href="#screencast-show-chapter-option-description" class="list-anchor">#</a>
    
    Необязательный текст описания, отображаемый под заголовком.
  - `Duration` [float]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-option-duration"/><a href="#screencast-show-chapter-option-duration" class="list-anchor">#</a>
    
    Время в миллисекундах, по истечении которого наложение автоматически удаляется. По умолчанию — `2000`.

**Возвращает**
- [void]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-chapter-return"/><a href="#screencast-show-chapter-return" class="list-anchor">#</a>

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.ShowOverlayAsync</x-search>

**Аргументы**
- `html` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-option-html"/><a href="#screencast-show-overlay-option-html" class="list-anchor">#</a>
  
  HTML-содержимое наложения.
- `options` `ScreencastShowOverlayOptions?` *(необязательно)*
  - `Duration` [float]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-option-duration"/><a href="#screencast-show-overlay-option-duration" class="list-anchor">#</a>
    
    Время в миллисекундах, по истечении которого наложение автоматически удаляется. Если параметр не указан, наложение остаётся до явного удаления.

**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-show-overlay-return"/><a href="#screencast-show-overlay-return" class="list-anchor">#</a>

### StartAsync {/* #screencast-start */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.59</font><x-search>screencast.StartAsync</x-search>

Запускает скринкаст. Если указан [Path](/api/class-screencast.mdx#screencast-start-option-path), сохраняет видеозапись в указанный файл. Если указан [OnFrame](/api/class-screencast.mdx#screencast-start-option-on-frame), передаёт кадры в формате JPEG в функцию обратного вызова. Оба параметра можно использовать одновременно.

**Использование**

**Аргументы**
- `options` `ScreencastStartOptions?` *(необязательно)*
  - `Fps` [int]? *(необязательно)* <font size="2">Добавлено в: v1.64</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-fps"/><a href="#screencast-start-option-fps" class="list-anchor">#</a>
    
    Частота кадров видеозаписи в кадрах в секунду. Используется только вместе с [Path](/api/class-screencast.mdx#screencast-start-option-path). По умолчанию — `25`.
    
    Более высокая частота кадров делает анимации и прокрутку плавнее, но увеличивает нагрузку на процессор при кодировании. Используйте вместе с [Size](/api/class-screencast.mdx#screencast-start-option-size) для записи видео в высоком разрешении. Видео может содержать лишь столько различных кадров, сколько создаёт браузер; в настоящее время Firefox и WebKit захватывают до 25 кадров в секунду.
  - `OnFrame` [Func]&lt;[ScreencastFrame], [Task]&gt; *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-on-frame"/><a href="#screencast-start-option-on-frame" class="list-anchor">#</a>
    - `Data` [byte]&#91;&#93;
      
      Данные кадра, закодированные в формате JPEG.
    - `Timestamp` [float]
      
      Временная метка момента отображения кадра браузером, в миллисекундах с начала эпохи Unix.
    - `ViewportWidth` [int]
      
      Ширина области просмотра страницы в момент захвата кадра.
    - `ViewportHeight` [int]
      
      Высота области просмотра страницы в момент захвата кадра.
    
    Функция обратного вызова, которая получает данные кадра в формате JPEG вместе с размерами области просмотра страницы в момент захвата.
  - `Path` [string]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-path"/><a href="#screencast-start-option-path" class="list-anchor">#</a>
    
    Путь, по которому должно быть сохранено видео после остановки скринкаста. Если указан, запускается запись видео.
  - `Quality` [int]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-quality"/><a href="#screencast-start-option-quality" class="list-anchor">#</a>
    
    Качество изображения в диапазоне от 0 до 100.
  - `Size` Size? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-option-size"/><a href="#screencast-start-option-size" class="list-anchor">#</a>
    - `Width` [int]
      
      Максимальная ширина кадра в пикселях.
    - `Height` [int]
      
      Максимальная высота кадра в пикселях.
    
    Задаёт размеры кадров скринкаста. Фактический кадр масштабируется с сохранением соотношения сторон страницы и может быть меньше указанных пределов. Если скринкаст уже активен (например, запущен при трассировке или записи видео), существующая конфигурация имеет приоритет, поэтому размер кадра может превышать эти пределы либо этот параметр может игнорироваться. Если параметр не указан, размер будет равен размеру области просмотра страницы, уменьшенному так, чтобы вписаться в 800×800.

**Возвращает**
- [Disposable]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="screencast-start-return"/><a href="#screencast-start-return" class="list-anchor">#</a>
