[WebMCP] предоставляет доступ к инструментам, которые фрейм регистрирует через экспериментальный браузерный API [WebMCP](https://webmachinelearning.github.io/webmcp/) — `navigator.modelContext`. Он позволяет получать список инструментов и вызывать их.

Экземпляры доступны через [Frame.Webmcp](/api/class-frame.mdx#frame-webmcp). [Page.Webmcp](/api/class-page.mdx#page-webmcp) — это экземпляр для главного фрейма.

:::note

WebMCP — экспериментальная возможность браузера. В Chromium она включается аргументом запуска `--enable-features=WebMCP`, в Firefox — настройками `dom.modelcontext.enabled` и `dom.modelcontext.testing.enabled`. В WebKit она не реализована.
:::

Названия инструментов, их описания, схемы входных данных и результаты предоставляются страницей, поэтому считайте их недоверенными входными данными.

## Методы

### CallToolAsync {/* #web-mcp-call-tool */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.64</font><x-search>webMCP.CallToolAsync</x-search>

Вызывает инструмент, зарегистрированный фреймом, и возвращает его результат. Результатом является значение, которым завершилась функция `execute` инструмента, — обычно это объект с массивом `content`. Результат с `isError: true` возвращается без изменений. Метод выбрасывает исключение, если инструмент не зарегистрирован или его функция `execute` выбрасывает исключение.

**Использование**

```csharp
await WebMCP.CallToolAsync(name, input, options);
```

**Аргументы**
- `name` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-name"/><a href="#web-mcp-call-tool-option-name" class="list-anchor">#</a>
  
  Название инструмента, возвращаемое методом [WebMCP.ToolsAsync()](/api/class-webmcp.mdx#web-mcp-tools).
- `input` [object]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-input"/><a href="#web-mcp-call-tool-option-input" class="list-anchor">#</a>
  
  Входные данные для инструмента, соответствующие его `inputSchema`. По умолчанию используется пустой объект.
- `options` `WebMCPCallToolOptions?` *(необязательно)*
  - `Timeout` [float]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-timeout"/><a href="#web-mcp-call-tool-option-timeout" class="list-anchor">#</a>
    
    Максимальное время ожидания в миллисекундах. По умолчанию — `30000` (30 секунд). Передайте `0`, чтобы отключить тайм-аут. Значение по умолчанию можно изменить с помощью методов [BrowserContext.SetDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) или [Page.SetDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout).

**Возвращаемое значение**
- [object]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-return"/><a href="#web-mcp-call-tool-return" class="list-anchor">#</a>

### ToolsAsync {/* #web-mcp-tools */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.64</font><x-search>webMCP.ToolsAsync</x-search>

Возвращает инструменты, зарегистрированные фреймом на текущий момент. Выбрасывает исключение, если браузер запущен без поддержки WebMCP. Параметры запуска, включающие эту поддержку, приведены в примечании выше.

[Page.Webmcp](/api/class-page.mdx#page-webmcp) охватывает только главный фрейм; дочерние фреймы предоставляют список своих инструментов через собственный [Frame.Webmcp](/api/class-frame.mdx#frame-webmcp).

**Использование**

```csharp
await WebMCP.ToolsAsync(options);
```

**Аргументы**
- `options` `WebMCPToolsOptions?` *(необязательно)*
  - `Timeout` [float]? *(необязательно)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-option-timeout"/><a href="#web-mcp-tools-option-timeout" class="list-anchor">#</a>
    
    Максимальное время ожидания в миллисекундах. По умолчанию — `30000` (30 секунд). Передайте `0`, чтобы отключить тайм-аут. Значение по умолчанию можно изменить с помощью методов [BrowserContext.SetDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) или [Page.SetDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout).

**Возвращаемое значение**
- [IReadOnlyList]&lt;Tools&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-return"/><a href="#web-mcp-tools-return" class="list-anchor">#</a>
  - `name` [string]
    
    Название инструмента, уникальное в пределах фрейма.
  - `description` [string]
    
    Описание инструмента.
  - `inputSchema` [object]? *(необязательно)*
    
    JSON Schema входных данных инструмента, если страница её предоставляет.
  - `annotations` Annotations? *(необязательно)*
    - `readOnly` [bool]? *(необязательно)*
      
      Инструмент не изменяет никакое состояние.
    - `untrustedContent` [bool]? *(необязательно)*
      
      Выходные данные инструмента могут содержать сторонний контент.
    - `consequential` [bool]? *(необязательно)*
      
      Инструмент выполняет действие со значимыми последствиями, например размещение заказа.
    
    Подсказки об инструменте, предоставляемые страницей.
