### HeadersArray {/* #api-response-headers-array */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.16</font><x-search>apiResponse.HeadersArray</x-search>

Массив со всеми HTTP-заголовками ответа, связанными с этим ответом. Имена заголовков не приводятся к нижнему регистру. Заголовки с несколькими записями, такие как `Set-Cookie`, появляются в массиве несколько раз.


  - `name` [string]
    
    Имя заголовка.
  - `value` [string]
    
    Значение заголовка.

### SecurityDetailsAsync {/* #api-response-security-details */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.61</font><x-search>apiResponse.SecurityDetailsAsync</x-search>

Возвращает информацию об SSL и другие сведения о безопасности. Возвращает `null` для ответов не по HTTPS. Для запросов с перенаправлениями возвращает информацию о последнем запросе в цепочке перенаправлений.

**Использование**

```csharp
await ApiResponse.SecurityDetailsAsync();
```

**Возвращает**
- SecurityDetails?<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="api-response-security-details-return"/><a href="#api-response-security-details-return" class="list-anchor">#</a>
  - `issuer` [string]? *(optional)*
    
    Компонент Common Name поля Issuer сертификата. Следует использовать только в информационных целях. Необязательно.
  - `protocol` [string]? *(optional)*
    
    Используемый протокол TLS (например, `TLS 1.3`). Необязательно.
  - `subjectName` [string]? *(optional)*
    
    Компонент Common Name поля Subject из сертификата. Следует использовать только в информационных целях. Необязательно.
  - `validFrom` [float]? *(optional)*
    
    Временная метка Unix (в секундах), указывающая, когда этот сертификат становится действительным. Необязательно.
  - `validTo` [float]? *(optional)*
    
    Временная метка Unix (в секундах), указывающая, когда этот сертификат становится недействительным. Необязательно.

### Timing {/* #api-response-timing */}

<font size="2" style={{position: "relative", top: "-20px"}}>Добавлено в: v1.62</font><x-search>apiResponse.Timing</x-search>

Возвращает временные характеристики загрузки ресурса для данного ответа. Для запросов с перенаправлениями возвращает информацию о последнем запросе в цепочке перенаправлений. Когда ответ предоставляется [из HAR-файла](../mock.mdx#replaying-from-har), временные характеристики недоступны и все значения равны -1. Дополнительную информацию см. в [Resource Timing API](https://developer.mozilla.org/en-US/docs/Web/API/PerformanceResourceTiming).

**Использование**

```csharp
ApiResponse.Timing
```

**Возвращает**
- Timing<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="api-response-timing-return"/><a href="#api-response-timing-return" class="list-anchor">#</a>
  - `startTime` [float]
    
    Время начала запроса в миллисекундах, прошедших с 1 января 1970 года 00:00:00 UTC.
  - `domainLookupStart` [float]
    
    Момент непосредственно перед началом поиска доменного имени ресурса клиентом. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `domainLookupEnd` [float]
    
    Момент непосредственно после завершения поиска доменного имени ресурса клиентом. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `connectStart` [float]
    
    Момент непосредственно перед началом установления клиентом соединения с сервером для получения ресурса. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `secureConnectionStart` [float]
    
    Момент непосредственно перед началом клиентом процесса рукопожатия для защиты текущего соединения. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `connectEnd` [float]
    
    Момент непосредственно после установления клиентом соединения с сервером для получения ресурса. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `requestStart` [float]
    
    Момент непосредственно перед началом запроса ресурса клиентом с сервера, из кеша или локального ресурса. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `responseStart` [float]
    
    Момент непосредственно после получения клиентом первого байта ответа от сервера, из кеша или локального ресурса. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
  - `responseEnd` [float]
    
    Момент непосредственно после получения клиентом последнего байта ресурса или непосредственно перед закрытием транспортного соединения, в зависимости от того, что произойдёт раньше. Значение указано в миллисекундах относительно `startTime`, -1, если недоступно.
