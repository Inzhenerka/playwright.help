# Возможности

Возможности определяют, какие инструменты сервер MCP предоставляет языковой модели (LLM). По умолчанию включены только основные инструменты. Добавьте возможности, чтобы получить доступ к дополнительным группам инструментов.

## Включение возможностей

Через аргумент командной строки:

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest", "--caps=vision,pdf,devtools"]
    }
  }
}
```

Через переменную окружения:

```bash
PLAYWRIGHT_MCP_CAPS=vision,pdf,devtools
```

Через файл конфигурации:

```json
{
  "capabilities": ["vision", "pdf", "devtools", "network", "storage", "testing"]
}
```

## Справочник возможностей

### core (всегда включена)

Базовая автоматизация браузера — всегда доступна, отключить нельзя.

| Инструмент | Описание |
|------|-------------|
| `browser_navigate` | Перейти по URL-адресу |
| `browser_navigate_back` | Вернуться назад по истории переходов |
| `browser_snapshot` | Создать снимок дерева доступности |
| `browser_find` | Найти в снимке текст или совпадения с регулярным выражением |
| `browser_click` | Нажать на элемент |
| `browser_hover` | Навести указатель на элемент |
| `browser_drag` | Выполнить перетаскивание между двумя элементами |
| `browser_drop` | Перетащить файлы или данные с указанным MIME-типом на элемент |
| `browser_select_option` | Выбрать вариант в раскрывающемся списке |
| `browser_type` | Ввести текст в элемент |
| `browser_press_key` | Нажать клавишу |
| `browser_fill_form` | Заполнить несколько полей формы |
| `browser_take_screenshot` | Сделать снимок экрана |
| `browser_run_code_unsafe` | Выполнить фрагмент кода Playwright |
| `browser_evaluate` | Выполнить JavaScript |
| `browser_wait_for` | Дождаться текста или истечения заданного времени |
| `browser_handle_dialog` | Принять или отклонить диалоговые окна |
| `browser_file_upload` | Загрузить файлы через диалог выбора файлов |
| `browser_console_messages` | Получить вывод консоли |
| `browser_network_requests` | Получить список сетевых запросов |
| `browser_network_request` | Показать полную информацию об одном запросе |
| `browser_tabs` | Управлять вкладками |
| `browser_close` | Закрыть страницу |
| `browser_resize` | Изменить размер окна |

### network

Мокирование сетевых запросов и управление состоянием сети.

| Инструмент | Описание |
|------|-------------|
| `browser_route` | Мокировать запросы, соответствующие шаблону URL |
| `browser_route_list` | Получить список активных маршрутов с моками |
| `browser_unroute` | Удалить маршруты с моками |
| `browser_network_state_set` | Установить состояние подключения к сети: онлайн или офлайн |

```json
"--caps=network"
```

### storage

Управление cookie, localStorage и sessionStorage, а также сохранение состояния.

| Инструмент | Описание |
|------|-------------|
| `browser_cookie_list/get/set/delete/clear` | Управлять cookie |
| `browser_localstorage_list/get/set/delete/clear` | Управлять localStorage |
| `browser_sessionstorage_list/get/set/delete/clear` | Управлять sessionStorage |
| `browser_storage_state` | Сохранить cookie и локальное хранилище в файл |
| `browser_set_storage_state` | Восстановить сохранённое состояние |

```json
"--caps=storage"
```

### testing

Проверки и генерация локаторов.

| Инструмент | Описание |
|------|-------------|
| `browser_verify_element_visible` | Проверить видимость элемента по роли и доступному имени |
| `browser_verify_text_visible` | Проверить видимость текста |
| `browser_verify_list_visible` | Проверить видимость списка и его элементов |
| `browser_verify_value` | Проверить значение поля формы |
| `browser_generate_locator` | Сгенерировать локатор Playwright для кода теста |

```json
"--caps=testing"
```

### vision

Инструменты управления мышью по координатам для сценариев работы на основе снимков экрана. Требуется LLM с поддержкой обработки изображений.

| Инструмент | Описание |
|------|-------------|
| `browser_mouse_move_xy` | Переместить указатель мыши в заданные координаты |
| `browser_mouse_click_xy` | Нажать в заданных координатах |
| `browser_mouse_drag_xy` | Выполнить перетаскивание между заданными координатами |
| `browser_mouse_down` | Нажать кнопку мыши |
| `browser_mouse_up` | Отпустить кнопку мыши |
| `browser_mouse_wheel` | Выполнить прокрутку колёсиком мыши |

```json
"--caps=vision"
```

Примеры использования см. в разделе [Режим работы с изображениями](./vision-mode.mdx).

### devtools

Трассировка, запись видео, запись действий, подсветка и отладка.

| Инструмент | Описание |
|------|-------------|
| `browser_start_tracing` | Начать запись трассировки выполнения |
| `browser_stop_tracing` | Остановить и сохранить трассировку |
| `browser_start_video` | Начать запись видео |
| `browser_stop_video` | Остановить и сохранить запись видео |
| `browser_video_chapter` | Добавить карточку главы |
| `browser_video_show_actions` | Сопровождать действия поясняющими выносками на странице |
| `browser_video_hide_actions` | Прекратить показ пояснений к действиям |
| `browser_start_recording` | Записывать действия пользователя в виде кода |
| `browser_stop_recording` | Остановить запись и вернуть код |
| `browser_highlight` | Показать подсвечивающую рамку вокруг элемента |
| `browser_hide_highlight` | Убрать подсвечивающую рамку |
| `browser_annotate` | Открыть панель Playwright Dashboard и собрать аннотации пользователя |
| `browser_resume` | Возобновить приостановленное выполнение скрипта |

```json
"--caps=devtools"
```

См. раздел [Инструменты отладки](./tools/devtools.mdx).

## Типовые конфигурации

### Минимальная (по умолчанию)

Только основные инструменты — навигация, снимки дерева доступности, нажатия, ввод текста, снимки экрана:

```json
["@playwright/mcp@latest"]
```

### Полная автоматизация

Всё включено:

```json
["@playwright/mcp@latest", "--caps=network,storage,testing,vision,pdf,devtools"]
```

### Сценарий тестирования

Основные инструменты + проверки testing + storage для сохранения состояния аутентификации:

```json
["@playwright/mcp@latest", "--caps=testing,storage"]
```

### Сценарий отладки

Основные инструменты + devtools для трассировки и записи видео:

```json
["@playwright/mcp@latest", "--caps=devtools"]
```

### Извлечение данных

Основные инструменты + network для мокирования запросов + storage для работы с cookie:

```json
["@playwright/mcp@latest", "--caps=network,storage"]
```

## Зачем нужны возможности

Возможности ограничивают количество инструментов, предоставляемых LLM. Меньше инструментов означает:

- **Меньшие затраты токенов** — схема инструментов занимает меньше места
- **Меньше галлюцинаций при вызове инструментов** — у LLM меньше вариантов, которые можно перепутать
- **Более быстрые ответы** — требуется обработать меньше контекста

Включайте только те возможности, которые нужны для вашего сценария использования.
