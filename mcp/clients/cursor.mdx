# Cursor

## Установка в один клик

[<img src="https://cursor.com/deeplink/mcp-install-dark.svg" alt="Установить в Cursor" />](https://cursor.com/en/install-mcp?name=Playwright&config=eyJjb21tYW5kIjoibnB4IEBwbGF5d3JpZ2h0L21jcEBsYXRlc3QifQ%3D%3D)

## Ручная настройка

Перейдите в `Cursor Settings` → `MCP` → `Add new MCP Server`.

- Имя: `playwright`
- Тип: `command`
- Команда: `npx @playwright/mcp@latest`

Вы также можете проверить конфигурацию или добавить аргументы, нажав `Edit`.
