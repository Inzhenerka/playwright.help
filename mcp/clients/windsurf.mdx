# Windsurf

## Установка

Следуйте [документации](https://docs.windsurf.com/windsurf/cascade/mcp) Windsurf по MCP и используйте [стандартную конфигурацию](../installation.mdx):

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```
