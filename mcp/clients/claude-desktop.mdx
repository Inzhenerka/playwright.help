# Claude Desktop

## Установка

Следуйте [руководству](https://modelcontextprotocol.io/quickstart/user) по установке MCP и добавьте следующее в конфигурацию Claude Desktop:

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

Расположение файла конфигурации зависит от вашей платформы:

| Платформа | Путь |
|----------|------|
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |
