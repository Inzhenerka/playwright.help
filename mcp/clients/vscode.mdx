## Установка через CLI

```bash
code --add-mcp '{"name":"playwright","command":"npx","args":["@playwright/mcp@latest"]}'
```

## Ручная настройка

Следуйте [руководству](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_add-an-mcp-server) по установке MCP и используйте [стандартную конфигурацию](../installation.mdx).

После установки сервер Playwright MCP будет доступен для использования с вашим агентом GitHub Copilot в VS Code.
