# Другие клиенты

Стандартная конфигурация работает с большинством MCP-клиентов. Чтобы узнать, где разместить конфигурацию, обратитесь к документации вашего клиента по MCP.

## Cline

Следуйте [руководству по настройке MCP-серверов](https://docs.cline.bot/mcp/configuring-mcp-servers). Добавьте в файл `cline_mcp_settings.json`:

```json
{
  "mcpServers": {
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "timeout": 30,
      "args": ["-y", "@playwright/mcp@latest"],
      "disabled": false
    }
  }
}
```

## Codex

```bash
codex mcp add playwright npx "@playwright/mcp@latest"
```

Или добавьте в файл `~/.codex/config.toml`:

```toml
[mcp_servers.playwright]
command = "npx"
args = ["@playwright/mcp@latest"]
```

## Copilot CLI

```bash
/mcp add
```

Или добавьте в файл `~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "playwright": {
      "type": "local",
      "command": "npx",
      "tools": ["*"],
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

## Goose

Перейдите в `Advanced settings` → `Extensions` → `Add custom extension`. Выберите тип `STDIO` и укажите команду `npx @playwright/mcp`.

## Kiro

Добавьте в файл `.kiro/settings/mcp.json`:

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

## Gemini CLI

Следуйте [руководству](https://github.com/google-gemini/gemini-cli/blob/main/docs/tools/mcp-server.md#configure-the-mcp-server-in-settingsjson) по установке MCP и используйте стандартную конфигурацию.

## opencode

Добавьте в файл `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "playwright": {
      "type": "local",
      "command": ["npx", "@playwright/mcp@latest"],
      "enabled": true
    }
  }
}
```
