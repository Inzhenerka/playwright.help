# Скриншоты

## browser_take_screenshot

Сделайте скриншот области просмотра, отдельного элемента или всей прокручиваемой страницы. Скриншоты предназначены для просмотра,
а не для взаимодействия — используйте `browser_snapshot`, чтобы получить идентификаторы элементов (`ref`) для взаимодействия с ними.

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `target` | string | нет | Идентификатор элемента (`ref`) или селектор для создания скриншота отдельного элемента |
| `type` | string | нет | `png`, `jpeg` или `webp`. Если не указан, определяется по расширению имени файла, иначе используется `png` |
| `filename` | string | нет | Файл для сохранения скриншота. Относительные имена разрешаются относительно корня рабочей области. По умолчанию — `page-{timestamp}.{ext}` в выходном каталоге |
| `fullPage` | boolean | нет | Сделать скриншот всей прокручиваемой страницы вместо области просмотра. Нельзя использовать вместе с `target` |
| `scale` | string | нет | `css` (по умолчанию) — размеры в CSS-пикселях; `device` — изображение высокого разрешения с учётом коэффициента пикселей устройства |

Если `filename` не указан, изображение также возвращается непосредственно в ответе инструмента, чтобы LLM могла его
увидеть. Передайте `--image-responses=omit`, чтобы исключить изображения из ответа.

### Скриншот страницы

```txt
Вы: Сделай скриншот текущей страницы.

→ browser_take_screenshot
  - [Скриншот области просмотра](page-2026-09-04T10-15-00-000Z.png)
```

### Скриншот элемента

```txt
Вы: Сделай скриншот только формы входа.

→ browser_take_screenshot { target: "e12" }
  - [Скриншот формы входа](element-2026-09-04T10-15-04-000Z.png)
```

### Скриншот всей страницы

```txt
Вы: Сделай скриншот всей страницы, включая содержимое ниже видимой области.

→ browser_take_screenshot { fullPage: true, filename: "homepage.png" }
  - [Скриншот всей страницы](homepage.png)
```

### Скриншот высокого разрешения

```txt
→ browser_take_screenshot { scale: "device", type: "webp" }
```

## Когда использовать скриншоты

Скриншоты дополняют снимки дерева доступности:

| Сценарий использования | Наиболее подходящий инструмент |
|----------|-----------|
| Взаимодействие с элементами | Идентификаторы элементов из снимка дерева доступности |
| Проверка визуального расположения элементов | Скриншот |
| Содержимое canvas/диаграмм | Скриншот |
| Документирование ошибки | Скриншот |
| Изучение структуры страницы | Снимок дерева доступности |
| Чтение текстового содержимого | Снимок дерева доступности |
