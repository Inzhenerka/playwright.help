# Загрузка файлов

## browser_file_upload

Обрабатывает диалоговые окна выбора файлов. Когда страница открывает диалог выбора файлов, ответ инструмента сообщает о модальном
состоянии, и все остальные инструменты отказываются выполнять действия, пока этот диалог не будет обработан:

```txt
### Modal state
- [File chooser]: can be handled by browser_file_upload
```

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `paths` | string[] | нет | Абсолютные пути к файлам для загрузки. Можно указать один файл или несколько файлов. Если параметр не указан, диалог выбора файлов отменяется |

```txt
→ browser_click { target: "e8" }

  ### Modal state
  - [File chooser]: can be handled by browser_file_upload

→ browser_file_upload { paths: ["/home/user/documents/report.pdf"] }

  - text: report.pdf selected
  - button "Upload" [ref=e12]

→ browser_click { target: "e12" }
```

### Несколько файлов

```txt
→ browser_file_upload {
    paths: [
      "/home/user/photos/image1.jpg",
      "/home/user/photos/image2.jpg"
    ]
  }
```

### Отмена диалога выбора файлов

```txt
→ browser_file_upload
```

## browser_drop

Перетаскивает файлы или данные с указанным MIME-типом на элемент, как если бы их перетащили извне страницы. Используйте этот инструмент для
областей загрузки с поддержкой перетаскивания, которые не открывают диалог выбора файлов. Необходимо указать хотя бы один из параметров: `paths` или `data`.

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `target` | string | да | Идентификатор элемента (`ref`) из снимка или уникальный селектор |
| `paths` | string[] | нет | Абсолютные пути к файлам для перетаскивания на элемент |
| `data` | object | нет | Данные для перетаскивания в виде сопоставления MIME-типов со строковыми значениями |

```txt
→ browser_drop {
    target: "e7",
    paths: ["/home/user/photos/image1.jpg"]
  }

→ browser_drop {
    target: "e12",
    data: { "text/plain": "hello", "text/uri-list": "https://example.com" }
  }
```

Для перетаскивания между двумя элементами, уже находящимися на странице, используйте [`browser_drag`](./interaction.mdx#browser_drag).

:::note
По умолчанию доступ к файлам ограничен путями внутри корневых каталогов рабочего пространства MCP. Используйте `--allow-unrestricted-file-access`, чтобы разрешить доступ к файлам из любых каталогов.
:::
