# Вкладки

## browser_tabs

Управляйте вкладками браузера — просматривайте список, создавайте, закрывайте или выбирайте вкладку.

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `action` | string | да | `list`, `new`, `close` или `select` |
| `index` | number | нет | Индекс вкладки, используется для `close`/`select`. Если не указан для `close`, закрывается текущая вкладка |
| `url` | string | нет | URL для перехода в новой вкладке, используется для `new` |

Каждое действие возвращает список вкладок после его выполнения.

### Просмотр списка всех вкладок

```txt
→ browser_tabs { action: "list" }

  - 0: [](about:blank)
  - 1: (current) [React • TodoMVC](https://demo.playwright.dev/todomvc)
  - 2: [Example Domain](https://example.com)
```

Вкладки нумеруются с 0, активная вкладка отмечается как `(current)`, а вкладка, в которой произошёл сбой, — как `[crashed]`.

### Открытие новой вкладки

```txt
→ browser_tabs { action: "new", url: "https://example.com" }
→ Возвращает снимок новой вкладки
```

Не указывайте `url`, чтобы открыть пустую вкладку.

### Переключение на вкладку

```txt
→ browser_tabs { action: "select", index: 1 }
```

### Закрытие вкладки

```txt
→ browser_tabs { action: "close" }           // закрыть текущую вкладку
→ browser_tabs { action: "close", index: 2 } // закрыть указанную вкладку
```
