# Диалоговые окна

Обрабатывайте диалоговые окна браузера (alert, confirm, prompt, beforeunload), которые блокируют взаимодействие со страницей.

## browser_handle_dialog

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `accept` | boolean | да | `true`, чтобы принять диалог, `false`, чтобы отклонить |
| `promptText` | string | нет | Текст для ввода в диалоговом окне prompt |

Пока диалоговое окно открыто, все остальные инструменты отказываются выполняться и вместо этого сообщают о модальном состоянии:

```txt
### Modal state
- ["alert" dialog with message "Alert"]: can be handled by browser_handle_dialog
```

Обработайте диалоговое окно, прежде чем продолжить.

### Диалоговое окно alert

```txt
→ browser_click { target: "e5" }

  ### Modal state
  - ["alert" dialog with message "Item deleted"]: can be handled by browser_handle_dialog

→ browser_handle_dialog { accept: true }
```

### Диалоговое окно confirm

```txt
→ browser_click { target: "e10" }

  ### Modal state
  - ["confirm" dialog with message "Are you sure you want to delete this?"]: can be handled by browser_handle_dialog

→ browser_handle_dialog { accept: true }     // нажать OK
→ browser_handle_dialog { accept: false }    // нажать «Отмена»
```

### Диалоговое окно prompt

```txt
→ browser_click { target: "e8" }

  ### Modal state
  - ["prompt" dialog with message "Enter your name:"]: can be handled by browser_handle_dialog

→ browser_handle_dialog { accept: true, promptText: "My new name" }
```

## Рабочий процесс

```txt
→ browser_click { target: "e12" }

  ### Modal state
  - ["confirm" dialog with message "Discard unsaved changes?"]: can be handled by browser_handle_dialog

→ browser_handle_dialog { accept: true }

→ browser_snapshot
  // Теперь страница отображает обновлённое состояние после принятия диалога
```

:::note
Окна выбора файлов отображаются таким же образом, но обрабатываются с помощью `browser_file_upload`, а не
`browser_handle_dialog`. См. раздел [Загрузка файлов](./file-upload.mdx).
:::
