# Экспорт в PDF

Сохранение текущей страницы в файл PDF. Требуется [возможность](../capabilities.mdx) **pdf**.

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest", "--caps=pdf"]
    }
  }
}
```

## browser_pdf_save

| Параметр | Тип | Обязательный | Описание |
|-----------|------|----------|-------------|
| `filename` | string | нет | Файл для сохранения PDF. Относительные пути разрешаются относительно корневого каталога рабочего пространства. По умолчанию используется имя `page-{timestamp}.pdf` в выходном каталоге |

```txt
→ browser_pdf_save
  - [Page as pdf](page-2026-09-04T10-15-00-000Z.pdf)

→ browser_pdf_save { filename: "invoice.pdf" }
  - [Page as pdf](invoice.pdf)
```

:::note
Генерация PDF поддерживается только в Chromium.
:::

## Сценарии использования

- Сохранение чеков или счетов из веб-приложений
- Архивирование веб-страниц для просмотра без подключения к интернету
- Генерация отчётов на основе панелей мониторинга
- Создание документации из HTML после рендеринга
