# Начало работы

## Предварительные требования

- [Node.js](https://nodejs.org/) версии 20 или новее
- MCP-клиент: VS Code, Cursor, Windsurf, Claude Code, Claude Desktop или аналогичный

## Установка

Добавьте MCP-сервер Playwright в свой клиент:

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

Инструкции для конкретного клиента приведены в разделе [Настройка клиента](./clients/vscode.mdx). Браузер загружается автоматически при первом использовании.

## Первое взаимодействие

Попросите своего ИИ-ассистента:

```txt
Перейди на https://demo.playwright.dev/todomvc и добавь несколько задач.
```

Ассистент вызывает инструменты MCP, чтобы открыть браузер, перейти на страницу и взаимодействовать с ней, — на каждом шаге возвращая снимки дерева доступности:

```txt
→ browser_navigate { url: "https://demo.playwright.dev/todomvc" }

  - heading "todos" [level=1] [ref=e3]
  - textbox "What needs to be done?" [ref=e5]

→ browser_type { target: "e5", text: "Buy groceries", submit: true }

  - heading "todos" [level=1] [ref=e3]
  - textbox "What needs to be done?" [ref=e5]
  - list [ref=e8]:
    - listitem [ref=e9]:
      - checkbox "Toggle Todo" [ref=e10]
      - text: Buy groceries
  - contentinfo [ref=e12]:
    - text: 1 item left
```

## Рабочий процесс

Каждое взаимодействие через MCP следует этому циклу:

1. **Переход** — `browser_navigate` открывает указанный URL
2. **Снимок** — инструменты возвращают дерево доступности с идентификаторами элементов (`ref`)
3. **Взаимодействие** — LLM передаёт идентификатор в качестве `target` для щелчка, ввода текста или заполнения поля
4. **Повторный снимок** — каждое действие возвращает обновленное состояние

По умолчанию браузер открывается **с графическим интерфейсом**, чтобы вы могли наблюдать за происходящим. Передайте `--headless` для запуска без видимого окна.

## Примеры запросов

```txt
Перейди на https://example.com и сделай снимок экрана.
```

```txt
Открой https://demo.playwright.dev/todomvc, добавь три задачи,
отметь первую как выполненную и сделай снимок экрана.
```

```txt
Перейди на https://news.ycombinator.com и перечисли первые 5 публикаций.
```

```txt
Сохрани текущее состояние браузера в auth.json, чтобы в следующий раз можно было пропустить вход в систему.
```
